## 1. Decisions

- **CSS layout (`app/globals.css`)**, in numbered, commented sections: 1 colour, 2 space/shape/depth/easing/layout, 3 type, `@theme inline` fonts, 4 plain `:root` variables (with `@variant md/lg/xl` overrides), 5 reduced motion, 6 composite `type-*` utilities, 7 base styles, 8 forced colors. Every reset in tokens.md §11.0 and typography.md §9 is there (`--color-*`, `--breakpoint-*`, `--radius-*`, `--shadow-*`, `--inset-shadow-*`, `--drop-shadow-*`, `--text-shadow-*`, `--ease-*`, `--animate-*`, `--font-*`, `--font-weight-*`, `--text-*`), plus the optional `--tracking-*` and `--leading-*` resets (the `--text-*` steps carry every line-height and tracking), and `--container-*: initial;` before the container tokens (so `max-w-md` etc. no longer exist; only `max-w-content`, `-prose`, `-wide` and the three measures). `sm` and `2xl` no longer exist. `--default-transition-duration: var(--duration-fast)` and `--default-transition-timing-function: var(--ease-standard)` in `@theme` make a bare `transition-colors` follow motion.md §1–§3 (hover and press colour changes run fast / standard); they are emitted when a utility uses them. **Sources:** `@import "tailwindcss" source(none)` plus `@source "../app"` and `@source "../components"` (and `@source not "./dev"`). Automatic detection also reads every non-ignored file, so in the real repo it scanned `/design`, `PROGRESS.md` and these specs (prose words and this spec's own code blocks) and put the dev page's utilities into every route's CSS (46.5 KB raw, measured during the build). A new code directory that carries class names must be added there. **The built CSS is minified with rewritten values:** times change unit (`--duration-fast:.15s` but `--stagger-tight:40ms`) and colours become hex (`--color-bg-scrim:#070914b8`). So JS never parses computed motion variables: **M1.18 and M2 GSAP code imports `lib/motion/tokens.ts`** (motion.md §7's optional constants module, now built): durations and staggers in seconds, distances in px, scales, GSAP ease names plus their CSS twins, and the §6.3 reduced-motion remap. `tests/e2e/tokens.spec.ts` parses `globals.css` and fails if any of those values drift from the module. (Colours read with `getComputedStyle`, e.g. by the M1.19 starfield, come back as hex, which canvas accepts.)
- **Colours go in `@theme static`** (the rest in plain `@theme`). It is still `@theme` (it drives `bg-*`/`text-*`/`border-*` utilities), but every colour is emitted, so `getComputedStyle` (M1.19 starfield colours, tests, the token page's swatches) always reads them. Cost measured: +2.3 KB raw, +0.5 KB gzipped. The other namespaces are emitted only when used, as tokens.md §11.0 describes. `--z-index-*` / `--transition-duration-*` theme keys: not used; those tokens stay plain `:root` variables (`z-(--z-header)`).
- **Composite type utilities** `type-display-1` … `type-nav` (`@utility`), one class per role: family + `text-<step>` + `uppercase` (eyebrow) + `lining-nums` (display steps) or `lining-nums tabular-nums` (prices). `em`/`i` inside `type-display-1/-2`, `type-h1`, `type-h2` switch to `font-display-italic`, italic, 500 (§6.2: never in h3/h4). Base: `html` gets `color-scheme: dark`, `font-synthesis-weight: none` and the page background; `body` gets `type-body bg-bg-page text-text-primary` and `overflow-wrap: break-word`; `strong, b` 600; `h1–h6` `text-wrap: balance`, `p` `pretty`; `::selection`; one `:focus-visible` outline (2px gold-300, 2px offset) everywhere; no global `antialiased`. Forced colors: decorative layers carry `data-decorative` and are `display: none` there (the hook M1.19 uses); everything else maps itself (outline, transparent borders, `currentColor`).
- **Reduced motion:** the `:root` remap from motion.md §6.3 plus the keyframe safety net (`animation-duration: 0.01ms`, one iteration, `scroll-behavior: auto`). Transitions are not zeroed.
- **Fonts (`app/fonts.ts`)**: the three calls QA validated (Jost `['400','500','600']`, Cormorant Garamond `['500','600']` normal, Cormorant italic `'500'` `preload: false`; latin, `swap`, `adjustFontFallback: true`, variables `--font-jost`, `--font-cormorant`, `--font-cormorant-italic`), `.variable` classes on `<html>`. Pinyon Script is not loaded. **One finding, no design change:** in Next 16.4 with Turbopack, passing the `fallback` option **drops** the generated metric-adjusted `"<Family> Fallback"` face (with it, `--font-jost` was `"Jost", ui-sans-serif, …`; without it, `"Jost", "Jost Fallback"` plus an `@font-face` with `size-adjust: 96.01%`, `ascent-override: 111.45%` on local Arial; Cormorant's uses local Times New Roman). So the calls omit `fallback`, and the typography.md §2 system stacks are appended in the `@theme inline` font tokens instead. Computed result, as the test asserts: body `Jost, "Jost Fallback", ui-sans-serif, system-ui, …`; h1 `"Cormorant Garamond", "Cormorant Garamond Fallback", Garamond, …`. design-agent may want the §9.1 "fallback" column reworded to "appended in CSS"; logged as a note, not a pushback.
- **Preload, measured from this build:** exactly two `<link rel=preload as=font>`: Jost latin **26,588 B** + Cormorant Garamond latin roman **37,776 B** = **64,364 B** (budget 120,000 B). The italic (23,900 B) is not preloaded. The test reads each preloaded href over HTTP and checks it byte-for-byte against `.next/static/media/…`.
- **Wordmark build (`scripts/wordmark/build-wordmark.ts`, `npm run wordmark:build`, tsx):** loads Next's bundled fontkit through `createRequire` (internal API, typed locally, never imported by app code), lays out "Starflames" with `kern` + `calt` (10 glyphs; fontkit's default `liga` etc. stay on), flips y, crops to the ink bounds plus half a stroke (so the hairline stroke is never clipped), scales by 0.5 (UPM 2048 → integer viewBox units), and writes one **relative, integer, letter-deduplicated path**: rounding happens once per absolute point, so relative steps carry no accumulated error. No SVGO. Output `components/brand/wordmark-path.ts` (generated, Prettier-formatted by the script): **viewBox `0 0 4074 1235`, stroke 43 units (= 1 CSS px at 28 px tall), path 5,866 B raw / 2,356 B gzipped**, module 6,454 B. Re-running it (with `--download`) produced a byte-identical file.
- **Pinyon woff2 is committed** (`scripts/wordmark/vendor/PinyonScript-latin.woff2`, Google Fonts v24 latin, 39,044 B, sha256 `3e1f69a2…6d3e42`, the same file QA measured) **with `OFL.txt`** next to it (from google/fonts `ofl/pinyonscript/OFL.txt`; "Copyright 2024 The Pinyon Project Authors"). Why: Google's file URLs are versioned and change, so the committed SVG must be reproducible from a known input; the OFL allows redistribution with the licence. It is dev-time input only: nothing under `scripts/` is bundled. `--download` refreshes it from the CSS API (latin block) when a new version is wanted.
- **Wordmark component (`components/brand/Wordmark.tsx`):** `WordmarkSprite` (rendered once, first in `<body>`): `<svg aria-hidden focusable=false width=0 height=0 class="absolute overflow-hidden">` holding `<symbol id="sf-wordmark" viewBox>` with one path, `fill` and `stroke` `currentColor`, `stroke-linejoin: round`, `paint-order: stroke`. `Wordmark({ size: "header" | "footer" })`: `<svg role="img" aria-label="Starflames" viewBox>` (same viewBox) with `<use href="#sf-wordmark">`, height `h-(--wordmark-h-header|footer)`, width auto from the viewBox. No `<title>`. Colour comes from the parent (`text-wordmark` on the token page; the header link in M1.15). Cost: the sprite sits in the HTML once and once more in the RSC payload (that is how App Router hydrates); gzip absorbs the second copy. Home HTML is 19.3 KB raw / 5.3 KB gzipped.
- **Root layout:** `lang="en"`, `suppressHydrationWarning` on `<html>`, the font variables, and the **hero-pending head script now** (motion.md §5.1). Why now: it is a root-layout concern, `suppressHydrationWarning` lands with it, and with no hero it does nothing visible (only `[data-hero-reveal]` is hidden, and the 2500 ms timer clears the class), so M2 only adds attributes and GSAP. It is testable today (added only when motion is allowed, always cleared). **CSP-ready:** the script is a constant string in `app/hero-pending.ts` (no interpolation), so a future CSP allows it by hash: `script-src 'sha256-sH4gQQZcFv/Ip7ejLZMtxhYKgQ8NOY4d/EspF/cN72c='` (recompute if the text changes). React 19 and `next dev` log no warning for it (checked).
- **App icon:** `app/icon.svg`, a gold-300 four-point star on a night-900 rounded square (readable on light and dark tabs), 212 B. Next emits `<link rel="icon" href="/icon.svg?…" type="image/svg+xml" sizes="any">`, so browsers stop asking for `/favicon.ico`. The M1.20 fixture's `/favicon.ico` allowlist is **removed**: every 404 fails a test again.
- **Dev-only token page: `/dev/tokens`** (`app/dev/tokens/page.tsx`). Gate: `app/dev/gate.ts` `requireDevPages()` calls `notFound()` when `NODE_ENV === "production"` and `ENABLE_DEV_PAGES !== "true"`. The pages are static, so the flag is read **at build time**. The Playwright webServer sets `ENABLE_DEV_PAGES=true`, so the e2e build contains the page and QA gets screenshots from the normal harness; a plain `npm run build` serves a 404 (verified: status 404 in the prerender meta). **Finding:** a `notFound()` in the layout alone still put the page's whole RSC payload into the 404 HTML (Next renders a layout and its page in parallel), so every dev page and its `generateMetadata` call the gate too; the layout keeps it as a backstop plus `robots: noindex`. Verified: the 404 HTML then contains no page content. `ENABLE_DEV_PAGES` is added to `.env.example` (server only, `false`), so `check:client-bundle` also guards it. Rejected: `pageExtensions` (next.config allows only `agentRules`) and a client-side gate (the page would ship).
- **Dev CSS stays out of production CSS.** Tailwind scans the whole project, and the token page uses nearly every utility, which put 16 KB raw / 2.2 KB gzipped of extra CSS on **every** route. So `globals.css` has `@source not "./dev"`, and `app/dev/dev.css` (imported by `app/dev/layout.tsx`, so only `/dev` routes load it) generates the dev utilities with `@reference "../globals.css"` and explicit `@source` files (a directory or glob source loses to the `not`; listed files don't; verified). Measured in the real repo (gzip default level): global CSS **20.4 KB raw / 4.9 KB gzipped**; dev CSS 19.3 KB / 3.3 KB, on `/dev/tokens` only. Not quite zero overlap: `@reference` also brings in `globals.css`'s `@source` directories, so the utilities the app uses outside `/dev` (today `.type-display-1` with its italic rule, the Wordmark's and the home page's classes, about 1.2 KB) and Tailwind's `@layer properties` / `@property` block (about 2.5 KB) are in both sheets, on `/dev` routes only. **Accepted (orchestrator decision):** a plain production build still emits the dev CSS chunk into `.next/static`, and the `/dev/tokens` 404 links it (so a visitor to that URL fetches it). It holds dev-page utilities only, no page content, and no production route links it.
- **Token page content** (screenshot-friendly, single column on 390, grids on md/xl): the wordmark at header size on bg-page and footer size on bg-sunken; every semantic colour role and raw scale with its reference and hex (**read from `app/globals.css` at build time**, so the page can't drift from the CSS); the type scale with typography.md §8 specimen copy (the body-lg production claim and the currency are open questions there, so body-lg reuses the body sample and prices show `34.00`); spacing steps; radii including `radius-arch` and both soft arches; the five shadows/glows; the five gradients; static CTA and ghost state samples (CTA samples 40 px apart, so no glow footprint holds another control, rule 9; the caption under each CTA sample sits inside its 26 px footprint, so it is `text-secondary`, not text-muted, X10); live CTA, ghost and a text link for the focus ring. Labels are dev-only tooling text, never shipped. The home page keeps its single h1 "Starflames", now `type-display-1` in a `px-(--gutter) py-(--section-y)` main.
- **Tests (`tests/e2e/tokens.spec.ts`, plus `/dev/tokens` in `ROUTES`):** computed body family (Jost + its fallback + stack), h1 family (Cormorant + fallback), body background/colour, `color-scheme: dark`, and Jost/Cormorant faces actually `loaded` on the token page; every `--color-*` name parsed from `globals.css` non-empty at runtime; `lib/motion/tokens.ts` equal to the motion variables, easings and reduced-motion remap parsed from `globals.css`; preload count 2 and bytes ≤ 120,000 (and equal to the build output); the icon link serves `image/svg+xml` 200; the wordmark has role img and name "Starflames" (twice on the token page), heights 28/40 at 390 and 36/48 at 1440, width > 3× height, one zero-size sprite that is not `display: none`, colour gold-300; `hasVisibleFocus` on the live CTA; the hero-pending class is added only when motion is allowed (`@motion`, so both twins run it) and is gone after the 2500 ms fallback; **CLS with fonts delayed 1 s** (forcing fallback-then-swap) on `/` and `/dev/tokens`, < 0.05. Measured CLS: 0.0000 (390) and 0.0003 (1440) on `/`, 0.0000 on `/dev/tokens` in the prototype; 0.0000 on both routes and both widths in the real-repo build.

// Hero entrance without a flash (motion.md §5.1). Inline and synchronous in <head>,
// before first paint: when motion is allowed, mark <html> `hero-pending` so that
// [data-hero-reveal] elements start hidden (globals.css), and reveal them anyway
// after 2500 ms if the hero's GSAP code never takes over. No JS or reduced motion:
// the class is never added, so nothing is hidden.
//
// Keep this a constant string (no interpolation): a future Content Security Policy
// allows it by hash, e.g. script-src 'sha256-<base64 of this exact text>'.
export const HERO_PENDING_SCRIPT = `(function(){try{if(matchMedia("(prefers-reduced-motion: no-preference)").matches){var d=document.documentElement;d.classList.add("hero-pending");setTimeout(function(){d.classList.remove("hero-pending")},2500)}}catch(e){}})()`;

// Run: npm run wordmark:build            (uses the vendored woff2)
//      npm run wordmark:build -- --download   (refreshes the woff2 from Google Fonts first)
// Uses the fontkit bundled inside Next (an internal API). App code never imports it.
import { createHash } from "node:crypto";
import { readFileSync, writeFileSync } from "node:fs";
import { createRequire } from "node:module";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";
import { gzipSync } from "node:zlib";

import { format, resolveConfig } from "prettier";

const TEXT = "Starflames";
const FEATURES = ["kern", "calt"]; // on top of fontkit's defaults (liga, ...)
const SCALE = 0.5; // viewBox units per font unit (UPM 2048 -> 1024); integers after rounding
const STROKE_AT_PX = 28; // the stroke renders 1 CSS px when the wordmark is this tall
const CSS_API =
  "https://fonts.googleapis.com/css2?family=Pinyon+Script&display=swap";
// A current Chrome UA, so the CSS API answers with woff2 URLs.
const UA =
  "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/153.0 Safari/537.36";

const here = dirname(fileURLToPath(import.meta.url));
const root = join(here, "..", "..");
const fontFile = join(here, "vendor", "PinyonScript-latin.woff2");
const outFile = join(root, "components", "brand", "wordmark-path.ts");

// Minimal typing of the bundled fontkit (it ships no .d.ts).
type PathCommand = {
  command:
    "moveTo" | "lineTo" | "quadraticCurveTo" | "bezierCurveTo" | "closePath";
  args: number[];
};
type GlyphPath = { commands: PathCommand[] };
type Run = {
  glyphs: { path: GlyphPath }[];
  positions: { xAdvance: number; xOffset: number; yOffset: number }[];
};
type Font = {
  unitsPerEm: number;
  postscriptName: string;
  version: string;
  layout: (text: string, features: string[]) => Run;
};
const require = createRequire(import.meta.url);
const fontkit = require("next/dist/compiled/@next/font/dist/fontkit") as {
  default: (buffer: Buffer) => Font;
};

async function download(): Promise<void> {
  const css = await (
    await fetch(CSS_API, { headers: { "user-agent": UA } })
  ).text();
  const url = /\/\* latin \*\/[^}]*?url\((https:[^)]+\.woff2)\)/.exec(css)?.[1];
  if (!url)
    throw new Error("latin woff2 URL not found in the Google Fonts CSS");
  const bytes = Buffer.from(await (await fetch(url)).arrayBuffer());
  writeFileSync(fontFile, bytes);
  console.log(`downloaded ${url} (${bytes.length} B)`);
}

/** Absolute font-unit commands -> one compact relative path in viewBox units. */
function toPath(commands: PathCommand[], dx: number, dy: number): string {
  // y is flipped (font units point up, SVG down) and every point is rounded once,
  // as an absolute value, so relative steps never accumulate rounding error.
  const pt = (x: number, y: number): [number, number] => [
    Math.round((x + dx) * SCALE),
    Math.round((dy - y) * SCALE),
  ];
  let out = "";
  let last = "";
  let [cx, cy] = [0, 0];
  let [sx, sy] = [0, 0];
  const num = (n: number): string => {
    const s = String(n);
    // A minus sign separates numbers on its own; otherwise a space (or nothing after a letter).
    return out.length === 0 || /[a-z]$/i.test(out) || s.startsWith("-")
      ? s
      : ` ${s}`;
  };
  const emit = (letter: string, points: [number, number][]): void => {
    if (letter !== last || letter === "m") out += letter;
    last = letter;
    // Every point of a segment (control points too) is relative to the segment start.
    for (const [x, y] of points) {
      out += num(x - cx);
      out += num(y - cy);
    }
  };
  for (const { command, args } of commands) {
    if (command === "closePath") {
      out += "z";
      last = "z";
      [cx, cy] = [sx, sy];
      continue;
    }
    const points: [number, number][] = [];
    for (let i = 0; i < args.length; i += 2)
      points.push(pt(args[i]!, args[i + 1]!));
    const end = points[points.length - 1]!;
    if (command === "moveTo") {
      emit("m", points);
      [sx, sy] = end;
    } else if (command === "lineTo") {
      emit("l", points);
    } else if (command === "quadraticCurveTo") {
      emit("q", points);
    } else {
      emit("c", points);
    }
    [cx, cy] = end;
  }
  return out;
}

async function main(): Promise<void> {
  if (process.argv.includes("--download")) await download();
  const bytes = readFileSync(fontFile);
  const font = fontkit.default(bytes);
  const run = font.layout(TEXT, FEATURES);

  // Place each glyph along the baseline (font units).
  const commands: PathCommand[] = [];
  let x = 0;
  run.glyphs.forEach((glyph, i) => {
    const pos = run.positions[i]!;
    for (const c of glyph.path.commands) {
      commands.push({
        command: c.command,
        args: c.args.map(
          (v, j) => v + (j % 2 === 0 ? x + pos.xOffset : pos.yOffset),
        ),
      });
    }
    x += pos.xAdvance;
  });

  // Tight ink bounds from the on-curve and control points (quadratic control points
  // can sit slightly outside the ink, which only adds a hair of margin).
  const xs = commands.flatMap((c) => c.args.filter((_, j) => j % 2 === 0));
  const ys = commands.flatMap((c) => c.args.filter((_, j) => j % 2 === 1));
  const [minX, maxX, minY, maxY] = [
    Math.min(...xs),
    Math.max(...xs),
    Math.min(...ys),
    Math.max(...ys),
  ];
  const inkH = Math.round((maxY - minY) * SCALE);
  const stroke = Math.round(inkH / STROKE_AT_PX);
  const pad = Math.ceil(stroke / 2); // the stroke's outer half, so it is never clipped
  const d = toPath(commands, -minX + pad / SCALE, maxY + pad / SCALE);
  const width = Math.round((maxX - minX) * SCALE) + 2 * pad;
  const height = inkH + 2 * pad;

  const sha = createHash("sha256").update(bytes).digest("hex");
  const source = `// GENERATED by scripts/wordmark/build-wordmark.ts. Do not edit by hand.
// "${TEXT}" in ${font.postscriptName} (${font.version.split(";")[0]}), features ${FEATURES.join(", ")}.
// Source woff2 sha256 ${sha}.
// The outlines are artwork made from an OFL font (scripts/wordmark/vendor/OFL.txt).

export const WORDMARK_VIEWBOX = "0 0 ${width} ${height}";
export const WORDMARK_WIDTH = ${width};
export const WORDMARK_HEIGHT = ${height};
/** Hairline thickening: ${stroke} viewBox units = 1 CSS px at ${STROKE_AT_PX}px tall. */
export const WORDMARK_STROKE = ${stroke};
export const WORDMARK_PATH =
  "${d}";
`;
  const config = (await resolveConfig(outFile)) ?? {};
  writeFileSync(
    outFile,
    await format(source, { ...config, filepath: outFile }),
  );
  console.log(
    `${run.glyphs.length} glyphs, viewBox 0 0 ${width} ${height}, stroke ${stroke}, ` +
      `path ${d.length} B (${gzipSync(d).length} B gzipped) -> ${outFile}`,
  );
}

main().catch((error: unknown) => {
  console.error(error);
  process.exit(1);
});

export const test = base.extend<{
  expectedIssues: RegExp[];
  pageIssues: string[];
}>({
  expectedIssues: [[], { option: true }],

      const issues: string[] = [];

        // For "Failed to load resource" the URL is only in the location.

import type { Locator, Page } from "@playwright/test";

/**
 * Presses Tab up to `max` times and returns a short label for each element that
 * receives focus (tag plus aria-label, text or id), stopping when focus leaves
 * the page or comes back to the first element. Wrap-around is detected by element
 * identity (two controls may share a label); the label is for display only.
 */
export async function tabOrder(page: Page, max = 50): Promise<string[]> {
  const labels: string[] = [];
  for (let i = 0; i < max; i += 1) {
    await page.keyboard.press("Tab");
    const label = await page.evaluate((isFirst) => {
      const w = window as Window & { __tabOrderFirst?: Element };
      const el = document.activeElement;
      if (!el || el === document.body) return null;
      if (isFirst) w.__tabOrderFirst = el;
      else if (el === w.__tabOrderFirst) return null;
      const name =
        el.getAttribute("aria-label") ??
        (el.textContent ?? "").trim().replace(/\s+/g, " ").slice(0, 40);
      return `${el.tagName.toLowerCase()}:${name || el.id}`;
    }, i === 0);
    if (label === null) break;
    labels.push(label);
  }
  await page.evaluate(() => {
    delete (window as Window & { __tabOrderFirst?: Element }).__tabOrderFirst;
  });
  return labels;
}

/**
 * Visible outline and box-shadow layers of the element, once its CSS
 * transitions have finished. Transparent or zero-alpha colours and zero widths
 * don't count, so Tailwind's resting `0 0 #0000` shadows are ignored.
 */
async function ringLayers(locator: Locator): Promise<string[]> {
  return locator.evaluate(async (el) => {
    await Promise.all(
      el
        .getAnimations()
        .filter((animation) => animation instanceof CSSTransition)
        .map((animation) => animation.finished.catch(() => undefined)),
    );
    const alpha = (color: string): number => {
      if (color === "transparent") return 0;
      const slash = /\/\s*([\d.]+)(%?)\s*\)$/.exec(color);
      if (slash) return Number(slash[1]) / (slash[2] ? 100 : 1);
      const rgba = /^rgba\([^,]+,[^,]+,[^,]+,\s*([\d.]+)\)$/.exec(color);
      return rgba ? Number(rgba[1]) : 1;
    };
    const style = getComputedStyle(el);
    const layers: string[] = [];
    if (
      style.outlineStyle !== "none" &&
      parseFloat(style.outlineWidth) > 0 &&
      alpha(style.outlineColor) > 0
    ) {
      layers.push(
        `outline ${style.outlineStyle} ${style.outlineWidth} ${style.outlineColor}`,
      );
    }
    if (style.boxShadow !== "none") {
      // Split the layer list on top-level commas (colours contain commas too).
      let depth = 0;
      let current = "";
      const shadows: string[] = [];
      for (const char of style.boxShadow) {
        if (char === "(") depth += 1;
        if (char === ")") depth -= 1;
        if (char === "," && depth === 0) {
          shadows.push(current.trim());
          current = "";
        } else {
          current += char;
        }
      }
      shadows.push(current.trim());
      for (const shadow of shadows) {
        const color =
          /(?:[a-z-]+\([^)]*\)|#[0-9a-f]+|transparent)/i.exec(shadow)?.[0] ??
          "currentcolor";
        const [x = 0, y = 0, blur = 0, spread = 0] = (
          shadow.replace(color, "").match(/-?[\d.]+px/g) ?? []
        ).map(parseFloat);
        const drawn = x !== 0 || y !== 0 || blur > 0 || spread > 0;
        if (drawn && alpha(color) > 0) layers.push(`shadow ${shadow}`);
      }
    }
    return layers;
  });
}

/**
 * True if focusing the element adds a visible outline or box-shadow layer that
 * it doesn't have while blurred. A ring drawn with a border or a pseudo-element
 * reads false: check the screenshot. Call it before any mouse interaction in the
 * test, since `:focus-visible` may not match a scripted focus after a click.
 */
export async function hasVisibleFocus(locator: Locator): Promise<boolean> {
  await locator.evaluate((el) => (el as HTMLElement).blur());
  const blurred = new Set(await ringLayers(locator));
  await locator.focus();
  const focused = await ringLayers(locator);
  return focused.some((layer) => !blurred.has(layer));
}

/**
 * Sum of layout-shift values (without recent input) once the fonts have settled.
 * layout-shift entries are only exposed to a buffered PerformanceObserver.
 */
async function layoutShift(page: Page): Promise<number> {
  return page.evaluate(async () => {
    await document.fonts.ready;
    return new Promise<number>((resolve) => {
      let total = 0;
      new PerformanceObserver((list) => {

          value: number;
          hadRecentInput: boolean;
        })[]) {
          if (!entry.hadRecentInput) total += entry.value;
        }
      }).observe({ type: "layout-shift", buffered: true });
      setTimeout(() => resolve(total), 500);
    });
  });
}

/** Motion variables of one CSS block as "group.camelName" -> seconds, px or a factor. */
function motionValues(block: string): Record<string, number> {
  const values: Record<string, number> = {};
  const pattern =
    /--(duration|stagger|motion-distance|motion-scale)-([a-z-]+):\s*([^;]+);/g;
  for (const [, group, name, raw] of block.matchAll(pattern)) {
    const camel = name!.replace(/-([a-z])/g, (_, c: string) => c.toUpperCase());
    const value = raw!.trim();
    const n = parseFloat(value);
    values[`${group}.${camel}`] = value.endsWith("ms") ? n / 1000 : n;
  }
  return values;
}

      Object.entries(values).map(([name, value]) => [
        `${group}.${name}`,
        value,
      ]),
    ),
  );
}
