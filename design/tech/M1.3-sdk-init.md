## 1. Dependencies and install scripts

| Package | Where | Version | Note |
|---|---|---|---|
| firebase | root dep | `^12.19.0` (lockfile: 12.19.0) | **Not 13.0.0 (`latest`)**: that major came out 2026-10-07, two days ago. Same rule as firebase-tools in M1.2: don't take a brand-new release. Revisit in M5. No peer deps. |
| firebase-admin | root dep | `^14.5.0` (14.5.0) | Same range as `/functions`. Engines `node >=22`. No peer deps. |
| server-only | root dep | `0.0.1` (exact) | Runtime dep, but it ships no code: Next replaces it internally. Stack-implied tooling. |
| tsx | root devDep | `4.23.15` (exact) | Runs the TS smoke script (and the M1.8 seed). Stack-implied tooling. |

Install with `npm install firebase@^12.19.0 firebase-admin@^14.5.0` and `npm install -E server-only@0.0.1`, then `npm install -D -E tsx@4.23.15`. Afterwards `npm ls` shows no invalid or missing peers (only the usual unmet *optional* platform binaries).

**Install scripts.** These two newly arrive with install scripts. Deny both (`npm deny-scripts @firebase/util esbuild`):
- `@firebase/util` (via firebase): its postinstall only bakes `FIREBASE_WEBAPP_CONFIG` into a stub for App Hosting auto-init. We never set that variable. Same reason it is denied in `/functions`.
- `esbuild` (via tsx): its postinstall checks the platform binary and only downloads it if the optional `@esbuild/<platform>` package is missing. On non-Windows it also swaps in a faster shim. The optional package installs normally, so tsx works without the script. Verified: after the deny, a clean `npm ci` reports "No packages with unreviewed install scripts" and `tsx` runs.

Root `allowScripts` becomes `{ "protobufjs": false, "re2": false, "unrs-resolver": false, "@firebase/util": false, "esbuild": false }`.

**Accepted risk (log in PROGRESS.md).** `npm audit --omit=dev` reports 4 high findings. All four come from one source: `@grpc/grpc-js@1.9.16`, which `@firebase/firestore` pins to `~1.9.0` (firebase 13.0.0 pins it too, so upgrading doesn't help). grpc-js is used only by the **Node** build of the client Firestore SDK, but that build does reach our server output: when a client component that imports `client.ts` is server-rendered, Next bundles the Node build, so grpc-js 1.9.16 lands in `.next/server/chunks/ssr` and in the nft trace. (The browser build, `dist/index.esm.js`, uses WebChannel and never imports grpc-js.) The risk is accepted because (1) the advisories (GHSA-m9gg-hp2v-232j, GHSA-f596-whhp-79r4) cover gRPC *server* behaviour (cert auth context and error messages), and we never run a gRPC server; and (2) every `client.ts` getter throws on the server (`typeof window === "undefined"`), so the server-side copy never opens a channel. `/functions` audit: 0. Admin's own grpc-js is 1.14.6. No `overrides`. **M5 note:** when the auth and cart hooks arrive, keep client-SDK consumers out of SSR (call the getters only in effects and handlers, or load the consumer with `next/dynamic` and `ssr: false`), or revisit this risk when firebase 13 or a grpc-js bump in `@firebase/firestore` lands.

## 2. Decisions

- **Files.** These live in `lib/firebase/` (replacing its `.gitkeep`). Inside `lib/firebase`, imports are relative so `tsx` resolves them without the `@/` alias.
  - `env.public.ts`: NEXT_PUBLIC parsing and the shared helpers. No `server-only`.
  - `env.server.ts`: `import "server-only"`.
  - `admin.ts`: `import "server-only"`.
  - `client.ts`: the browser SDK.
- **Env split.** `env.public.ts` references every `process.env.NEXT_PUBLIC_*` **literally**, as the default argument. Next inlines only literal references (docs `02-guides/environment-variables.md`: "dynamic lookups will not be inlined"). `env.server.ts` reads `process.env` at call time, and `server-only` keeps it out of client graphs. Both readers take an optional raw-env argument, so the smoke script can test the guards without touching `process.env`. Errors are `FirebaseEnvError`, and each one names the variable and the fix. Validation is **lazy**: it runs on the first getter call, not on import. So `next build` on a fresh clone without `.env.local` still passes (verified).
- **Project ID.** There is one source of truth, `NEXT_PUBLIC_FIREBASE_PROJECT_ID`, read by both sides. The value isn't secret. Next inlines it into server bundles at build time too, which is fine until the production task. The demo storage bucket is `${projectId}.appspot.com` (the bucket M1.2 probed), and the demo authDomain is `${projectId}.firebaseapp.com`. No new variables are needed.
- **Prod guard (Admin).** These rules apply, in order:
  1. A non-`demo-*` project throws, unless `FIREBASE_ALLOW_NON_DEMO_PROJECT=true`.
  2. Even with the flag, `getAdminApp()` throws "production credentials are not implemented yet". The planned shape is in a code comment: `initializeApp({ projectId, credential: applicationDefault(), storageBucket })`, with ADC from the hosting runtime and never a key file.
  3. A demo project needs **all three** Admin emulator hosts. A partial config throws and lists the missing variables. This is the dangerous case: for example, Firestore on the emulator while Auth falls through to Google.
  4. Hosts must be `host:port` with no protocol. firebase-admin itself rejects `http://` for Storage.
- **Admin singleton.** A named app (`starflames-admin`) is looked up with `getApps()` before `initializeApp`. It is synchronous, so there is no race. firebase-admin is already on Next's built-in `serverExternalPackages` list (`next/dist/lib/server-external-packages.jsonc`). The build shows it loaded as an external (`a.y("firebase-admin-<hash>/app")`), so **no `next.config.ts` change** is needed, and its app registry outlives HMR of our modules. Verified in `next dev`: three edits to `admin.ts`, with each request returning 200 and no "app already exists" error. In emulator mode we pass **no credential**. firebase-admin's Firestore wrapper rejects custom credentials, and with the `*_EMULATOR_HOST` variables set, all traffic is local. `firestore.settings()` is not called; converters and settings belong to M1.4.
- **`METADATA_SERVER_DETECTION=none`** (a new server variable in `.env.example`). Without it, the first Admin Firestore call makes google-auth-library probe the GCE metadata server. That costs about 3 s and an outbound DNS/HTTP attempt, plus a `MetadataLookupWarning`. Measured: 3265 ms → 185 ms. It is for emulator dev only. `next dev`, `next build` and `next start` all load `.env.local` (Next skips it only when `NODE_ENV=test`), so nothing in Next keeps it out of production. **Note for the production-setup task:** deployments must not ship `.env.local`. If one did, `METADATA_SERVER_DETECTION=none` would disable ADC's metadata-server lookup on the hosting runtime, and the `*_EMULATOR_HOST` variables would route Admin traffic to emulators that don't exist there.
- **Client.**
  - **Lazy and browser-only.** Import has no side effects. Each getter creates its service on first call. `getClientApp()` throws on the server (`typeof window === "undefined"`), because a client SDK on the server would share auth state across requests. So SSR of a client component that imports the module is safe (verified: 200), and getters belong in effects and handlers. The file has **no `"use client"` directive**: that is for component boundaries, and it would turn these exports into client references when imported from a Server Component.
  - **Connect exactly once.** Instances are cached on `globalThis.__starflamesFirebaseClient`. HMR re-evaluates our module but keeps the Firebase SDK and `globalThis`, so `connect*Emulator` never runs twice. Proof from the prototype: a second `connectAuthEmulator` on a used Auth throws `auth/emulator-config-failed`. With the cache, a fresh module instance returns the same four instances without throwing.
  - **Placeholder apiKey.** A demo project has no web API key. The emulators accept any non-empty key, and Auth throws `auth/invalid-api-key` on an empty one. So `client.ts` uses the constant `"demo-api-key"`, and only on the demo path, because `readPublicFirebaseEnv()` refuses non-demo projects. It is not a secret and not a real key. The production web config (apiKey, appId, real bucket) is out of scope; the client refuses non-demo projects until then. The prototype signed up a user against the Auth emulator with this key.
  - **Functions region.** `us-central1`, matching `/functions`.
  - **Emulator banner.** `disableWarnings: true` hides the Auth emulator banner, which would cover the layout in the 390px screenshots. Safety comes from the demo-only guard.
  - **Firestore cache.** No persistent cache yet. That's M5 (cart sync).
- **Enforcement** has three layers:
  1. `server-only` in `admin.ts` and `env.server.ts`. Verified: a `"use client"` component importing `admin.ts` fails `next build` with "You're importing a module that depends on "server-only"…", with traces for both files.
  2. An ESLint `no-restricted-imports` block on `app/**`, `components/**` and `lib/**` (except `lib/firebase/**`). It forbids `firebase`, `firebase/*`, `firebase-admin`, `firebase-admin/*`, `@firebase/*` and `@google-cloud/*`. It also forbids the init modules: any specifier ending in `firebase/{admin,client,env.server,env.public}` (regex `(^|/)firebase/(admin|client|env\.(server|public))$`). That catches `@/lib/firebase/admin`, `../../lib/firebase/client`, and the short relative forms `./firebase/client` (from `lib/cart.ts`) and `../firebase/admin` (from `lib/types/x.ts`). UI goes through repositories (M1.6) and client hooks. It uses `regex`, not gitignore `group`, because `group: ["firebase"]` also matched `@/lib/firebase/...` and would have blocked the future repositories. The probe flagged all seven bad imports in section 5(b) and allowed `@/lib/firebase/repositories`. Dynamic `import()` is not covered; server-only and the bundle check catch the admin side.
  3. `npm run check:client-bundle` after build. It scans `.next/static` for server packages and for the name of every non-`NEXT_PUBLIC_` variable in `.env.example`, matching the whole name only, so `NEXT_PUBLIC_FIRESTORE_EMULATOR_HOST` doesn't trigger `FIRESTORE_EMULATOR_HOST`. The prototype passed with a client page that used `client.ts` (firebase was in the bundle, firebase-admin was not). It failed (exit 1) when the probe printed a server variable name.
- **Smoke script.** `npm run smoke:firebase` = `tsx --conditions=react-server scripts/smoke-firebase.ts`. Outside Next, `server-only`'s default export throws. The `react-server` condition resolves it to its empty module, as Next does for Server Components. That condition is the only change from plain tsx, and the M1.8 seed needs it too. The script:
  1. loads `.env.local`, else `.env.example`, with `process.loadEnvFile`; the shell environment wins.
  2. asserts the env guards.
  3. preflights the three emulator ports with a 2 s TCP connect, so it exits 1 within a few seconds (immediate connection refusal, no SDK retry) instead of hanging while the SDK retries (measured >2 min without it).
  4. does a Firestore write + read, Auth `createUser` + lookup, and Storage upload + download.
  5. cleans up in `finally`, then verifies the cleanup.
- **Client exercised when?** Now: tsc, lint, the bundle check, and the prototype evidence above. In a real browser: **M5** (auth and cart hooks), covered by the M1.20 Playwright harness. This task ships no client consumer and no dev page, because those would be unspecced UI.
- **Out of scope:** repositories (M1.6), converters, domain types and Firestore settings (M1.4), and the production config and credentials (after user approval).

**lib/firebase/env.public.ts**
```ts
/**
 * Public (browser-safe) Firebase env. Reads NEXT_PUBLIC_* only.
 * Each variable is referenced literally so Next can inline it into client bundles;
 * a dynamic `process.env[name]` lookup would not be inlined.
 */

export class FirebaseEnvError extends Error {
  override name = "FirebaseEnvError";
}

export type HostPort = { host: string; port: number };

export type PublicFirebaseEnv = {
  projectId: string;
  storageBucket: string;
  authDomain: string;
  /** Always set for now: demo projects only exist in the emulators. */
  emulators: {
    firestore: HostPort;
    auth: HostPort;
    storage: HostPort;
    functions: HostPort;
  };
};

export type RawPublicFirebaseEnv = {
  NEXT_PUBLIC_FIREBASE_PROJECT_ID: string | undefined;
  NEXT_PUBLIC_USE_FIREBASE_EMULATORS: string | undefined;
  NEXT_PUBLIC_FIRESTORE_EMULATOR_HOST: string | undefined;
  NEXT_PUBLIC_AUTH_EMULATOR_HOST: string | undefined;
  NEXT_PUBLIC_STORAGE_EMULATOR_HOST: string | undefined;
  NEXT_PUBLIC_FUNCTIONS_EMULATOR_HOST: string | undefined;
};

const HINT =
  "Copy .env.example to .env.local (see design/tech/M1.3-sdk-init.md).";

/** "demo-" project IDs exist only in the Emulator Suite and can never reach production. */
export function isDemoProjectId(projectId: string): boolean {
  return projectId.startsWith("demo-");
}

export function requireValue(name: string, value: string | undefined): string {
  const trimmed = value?.trim();
  if (!trimmed) {
    throw new FirebaseEnvError(`${name} is not set. ${HINT}`);
  }
  return trimmed;
}

/** Parses "host:port" (no protocol), e.g. "127.0.0.1:6104". */
export function parseHostPort(
  name: string,
  value: string | undefined,
): HostPort {
  const raw = requireValue(name, value);
  const match = /^([A-Za-z0-9.-]+):(\d{1,5})$/.exec(raw);
  const port = match ? Number(match[2]) : NaN;
  if (!match || !match[1] || port < 1 || port > 65535) {
    throw new FirebaseEnvError(
      `${name} must be "host:port" without a protocol (e.g. 127.0.0.1:6104), got "${raw}".`,
    );
  }
  return { host: match[1], port };
}

export function readPublicFirebaseEnv(
  raw: RawPublicFirebaseEnv = {
    NEXT_PUBLIC_FIREBASE_PROJECT_ID:
      process.env.NEXT_PUBLIC_FIREBASE_PROJECT_ID,
    NEXT_PUBLIC_USE_FIREBASE_EMULATORS:
      process.env.NEXT_PUBLIC_USE_FIREBASE_EMULATORS,
    NEXT_PUBLIC_FIRESTORE_EMULATOR_HOST:
      process.env.NEXT_PUBLIC_FIRESTORE_EMULATOR_HOST,
    NEXT_PUBLIC_AUTH_EMULATOR_HOST: process.env.NEXT_PUBLIC_AUTH_EMULATOR_HOST,
    NEXT_PUBLIC_STORAGE_EMULATOR_HOST:
      process.env.NEXT_PUBLIC_STORAGE_EMULATOR_HOST,
    NEXT_PUBLIC_FUNCTIONS_EMULATOR_HOST:
      process.env.NEXT_PUBLIC_FUNCTIONS_EMULATOR_HOST,
  },
): PublicFirebaseEnv {
  const projectId = requireValue(
    "NEXT_PUBLIC_FIREBASE_PROJECT_ID",
    raw.NEXT_PUBLIC_FIREBASE_PROJECT_ID,
  );
  const useEmulators = requireValue(
    "NEXT_PUBLIC_USE_FIREBASE_EMULATORS",
    raw.NEXT_PUBLIC_USE_FIREBASE_EMULATORS,
  );
  if (useEmulators !== "true" && useEmulators !== "false") {
    throw new FirebaseEnvError(
      `NEXT_PUBLIC_USE_FIREBASE_EMULATORS must be "true" or "false", got "${useEmulators}".`,
    );
  }
  if (!isDemoProjectId(projectId)) {
    // Production web config (apiKey, appId, real bucket) lands with the production-setup task.
    throw new FirebaseEnvError(
      `NEXT_PUBLIC_FIREBASE_PROJECT_ID is "${projectId}". Only "demo-*" projects are supported until the user approves a real project.`,
    );
  }
  if (useEmulators !== "true") {
    throw new FirebaseEnvError(
      `Project "${projectId}" is a demo project, which only exists in the emulators. Set NEXT_PUBLIC_USE_FIREBASE_EMULATORS=true.`,
    );
  }
  return {
    projectId,
    storageBucket: `${projectId}.appspot.com`,
    authDomain: `${projectId}.firebaseapp.com`,
    emulators: {
      firestore: parseHostPort(
        "NEXT_PUBLIC_FIRESTORE_EMULATOR_HOST",
        raw.NEXT_PUBLIC_FIRESTORE_EMULATOR_HOST,
      ),
      auth: parseHostPort(
        "NEXT_PUBLIC_AUTH_EMULATOR_HOST",
        raw.NEXT_PUBLIC_AUTH_EMULATOR_HOST,
      ),
      storage: parseHostPort(
        "NEXT_PUBLIC_STORAGE_EMULATOR_HOST",
        raw.NEXT_PUBLIC_STORAGE_EMULATOR_HOST,
      ),
      functions: parseHostPort(
        "NEXT_PUBLIC_FUNCTIONS_EMULATOR_HOST",
        raw.NEXT_PUBLIC_FUNCTIONS_EMULATOR_HOST,
      ),
    },
  };
}
```

**lib/firebase/env.server.ts**
```ts
import "server-only";

import {
  FirebaseEnvError,
  isDemoProjectId,
  parseHostPort,
  requireValue,
  type HostPort,
} from "./env.public";

export type ServerFirebaseEnv =
  | {
      mode: "emulator";
      projectId: string;
      storageBucket: string;
      emulators: { firestore: HostPort; auth: HostPort; storage: HostPort };
    }
  | {
      /** Unlocked by FIREBASE_ALLOW_NON_DEMO_PROJECT=true. Credentials are not wired yet. */
      mode: "production";
      projectId: string;
    };

type RawServerEnv = Partial<Record<string, string>>;

const EMULATOR_VARS = [
  "FIRESTORE_EMULATOR_HOST",
  "FIREBASE_AUTH_EMULATOR_HOST",
  "FIREBASE_STORAGE_EMULATOR_HOST",
] as const;

/**
 * Server-only Firebase env. `firebase-admin` itself reads the *_EMULATOR_HOST variables
 * from process.env; this function only validates them, so a missing or partial emulator
 * config fails loudly instead of silently sending traffic to Google.
 */
export function readServerFirebaseEnv(
  raw: RawServerEnv = process.env,
): ServerFirebaseEnv {
  const projectId = requireValue(
    "NEXT_PUBLIC_FIREBASE_PROJECT_ID",
    raw.NEXT_PUBLIC_FIREBASE_PROJECT_ID,
  );

  if (!isDemoProjectId(projectId)) {
    if (raw.FIREBASE_ALLOW_NON_DEMO_PROJECT !== "true") {
      throw new FirebaseEnvError(
        `Refusing to initialise firebase-admin for non-demo project "${projectId}". ` +
          `Use a "demo-*" project ID, or set FIREBASE_ALLOW_NON_DEMO_PROJECT=true once the user has approved production.`,
      );
    }
    return { mode: "production", projectId };
  }

  const missing = EMULATOR_VARS.filter((name) => !raw[name]?.trim());
  if (missing.length > 0) {
    throw new FirebaseEnvError(
      `Demo project "${projectId}" needs every Admin emulator host; missing: ${missing.join(", ")}. ` +
        `Copy .env.example to .env.local and start the emulators with \`npm run emulators\`.`,
    );
  }

  return {
    mode: "emulator",
    projectId,
    storageBucket: `${projectId}.appspot.com`,
    emulators: {
      firestore: parseHostPort(
        "FIRESTORE_EMULATOR_HOST",
        raw.FIRESTORE_EMULATOR_HOST,
      ),
      auth: parseHostPort(
        "FIREBASE_AUTH_EMULATOR_HOST",
        raw.FIREBASE_AUTH_EMULATOR_HOST,
      ),
      storage: parseHostPort(
        "FIREBASE_STORAGE_EMULATOR_HOST",
        raw.FIREBASE_STORAGE_EMULATOR_HOST,
      ),
    },
  };
}
```

**lib/firebase/admin.ts**
```ts
import "server-only";

import { getApps, initializeApp, type App } from "firebase-admin/app";
import { getAuth, type Auth } from "firebase-admin/auth";
import { getFirestore, type Firestore } from "firebase-admin/firestore";
import { getStorage, type Storage } from "firebase-admin/storage";

import { readServerFirebaseEnv } from "./env.server";

/** Named app, so it never collides with a default app created by other tooling. */
const ADMIN_APP_NAME = "starflames-admin";

/**
 * Lazy singleton. firebase-admin keeps its app registry in its own module scope, and Next
 * loads firebase-admin as an external Node package (it is on Next's built-in
 * serverExternalPackages list), so the registry survives dev HMR of our modules.
 * Looking the app up by name first makes re-evaluation of this file harmless.
 */
export function getAdminApp(): App {
  const existing = getApps().find((app) => app.name === ADMIN_APP_NAME);
  if (existing) return existing;

  const env = readServerFirebaseEnv();
  if (env.mode === "production") {
    // Planned shape (production-setup task, after user approval):
    //   initializeApp({ projectId: env.projectId, credential: applicationDefault(), storageBucket }, ADMIN_APP_NAME)
    // No service-account keys: ADC comes from the hosting runtime.
    throw new Error(
      `firebase-admin production credentials are not implemented yet (project "${env.projectId}").`,
    );
  }

  // Emulator mode: no credential. firebase-admin routes Firestore, Auth and Storage to the
  // hosts in FIRESTORE_EMULATOR_HOST / FIREBASE_AUTH_EMULATOR_HOST / FIREBASE_STORAGE_EMULATOR_HOST.
  return initializeApp(
    { projectId: env.projectId, storageBucket: env.storageBucket },
    ADMIN_APP_NAME,
  );
}

export function getAdminFirestore(): Firestore {
  return getFirestore(getAdminApp());
}

export function getAdminAuth(): Auth {
  return getAuth(getAdminApp());
}

export function getAdminStorage(): Storage {
  return getStorage(getAdminApp());
}
```

**lib/firebase/client.ts**
```ts
import { getApp, getApps, initializeApp, type FirebaseApp } from "firebase/app";
import { connectAuthEmulator, getAuth, type Auth } from "firebase/auth";
import {
  connectFirestoreEmulator,
  getFirestore,
  type Firestore,
} from "firebase/firestore";
import {
  connectFunctionsEmulator,
  getFunctions,
  type Functions,
} from "firebase/functions";
import {
  connectStorageEmulator,
  getStorage,
  type FirebaseStorage,
} from "firebase/storage";

import { readPublicFirebaseEnv } from "./env.public";

/**
 * Browser-only Firebase client SDK. Importing this file has no side effects; each service is
 * created and connected to its emulator on the first getter call (in an effect or event
 * handler, never during render on the server).
 */

/** The emulators accept any API key; a demo project has no real one. Not a secret. */
const DEMO_API_KEY = "demo-api-key";

/** Must match the Functions region in /functions (default us-central1). */
const FUNCTIONS_REGION = "us-central1";

type ClientCache = {
  auth?: Auth;
  firestore?: Firestore;
  storage?: FirebaseStorage;
  functions?: Functions;
};

// Kept on globalThis so dev HMR, which re-evaluates this module but keeps the Firebase SDK
// instances alive, never calls connect*Emulator twice on the same instance (that throws).
const globalForFirebase = globalThis as typeof globalThis & {
  __starflamesFirebaseClient?: ClientCache;
};

function cache(): ClientCache {
  return (globalForFirebase.__starflamesFirebaseClient ??= {});
}

function assertBrowser(): void {
  if (typeof window === "undefined") {
    throw new Error(
      "lib/firebase/client is browser-only. Use the server repositories (Admin SDK) on the server.",
    );
  }
}

export function getClientApp(): FirebaseApp {
  assertBrowser();
  if (getApps().length > 0) return getApp();
  const env = readPublicFirebaseEnv();
  return initializeApp({
    apiKey: DEMO_API_KEY,
    projectId: env.projectId,
    authDomain: env.authDomain,
    storageBucket: env.storageBucket,
  });
}

export function getClientAuth(): Auth {
  const c = cache();
  if (!c.auth) {
    const auth = getAuth(getClientApp());
    const { host, port } = readPublicFirebaseEnv().emulators.auth;
    // disableWarnings: hides the emulator banner, which would overlay the layout in screenshots.
    connectAuthEmulator(auth, `http://${host}:${port}`, {
      disableWarnings: true,
    });
    c.auth = auth;
  }
  return c.auth;
}

export function getClientFirestore(): Firestore {
  const c = cache();
  if (!c.firestore) {
    const firestore = getFirestore(getClientApp());
    const { host, port } = readPublicFirebaseEnv().emulators.firestore;
    connectFirestoreEmulator(firestore, host, port);
    c.firestore = firestore;
  }
  return c.firestore;
}

export function getClientStorage(): FirebaseStorage {
  const c = cache();
  if (!c.storage) {
    const storage = getStorage(getClientApp());
    const { host, port } = readPublicFirebaseEnv().emulators.storage;
    connectStorageEmulator(storage, host, port);
    c.storage = storage;
  }
  return c.storage;
}

export function getClientFunctions(): Functions {
  const c = cache();
  if (!c.functions) {
    const functions = getFunctions(getClientApp(), FUNCTIONS_REGION);
    const { host, port } = readPublicFirebaseEnv().emulators.functions;
    connectFunctionsEmulator(functions, host, port);
    c.functions = functions;
  }
  return c.functions;
}
```

```ts
/** Fails fast; otherwise the SDKs keep retrying against a closed port. */
function assertReachable(
  name: string,
  { host, port }: HostPort,
): Promise<void> {
  return new Promise((resolve, reject) => {
    const socket = connect({ host, port, timeout: 2000 });
    const fail = (): void => {
      socket.destroy();
      reject(
        new Error(
          `${name} emulator is not reachable on ${host}:${port}. Start it with \`npm run emulators\`.`,
        ),
      );
    };
    socket.once("connect", () => {
      socket.end();
      resolve();
    });
    socket.once("timeout", fail);
    socket.once("error", fail);
  });
}

function checkGuards(): void {
  const hosts = {
    FIRESTORE_EMULATOR_HOST: "127.0.0.1:6104",
    FIREBASE_AUTH_EMULATOR_HOST: "127.0.0.1:6106",
    FIREBASE_STORAGE_EMULATOR_HOST: "127.0.0.1:6107",
  };
  assert.throws(
    () =>
      readServerFirebaseEnv({
        NEXT_PUBLIC_FIREBASE_PROJECT_ID: "real-project",
        ...hosts,
      }),

  );
  assert.equal(
    readServerFirebaseEnv({
      NEXT_PUBLIC_FIREBASE_PROJECT_ID: "real-project",
      FIREBASE_ALLOW_NON_DEMO_PROJECT: "true",
    }).mode,

  );
  assert.throws(
    () =>
      readServerFirebaseEnv({
        NEXT_PUBLIC_FIREBASE_PROJECT_ID: "demo-starflames",

      }),
    /missing: FIREBASE_AUTH_EMULATOR_HOST, FIREBASE_STORAGE_EMULATOR_HOST/,
  );
  assert.throws(
    () =>
      readServerFirebaseEnv({
        NEXT_PUBLIC_FIREBASE_PROJECT_ID: "demo-starflames",
        ...hosts,
        FIRESTORE_EMULATOR_HOST: "http://127.0.0.1:6104",
      }),
    /without a protocol/,
  );

  const publicEnv = {

    NEXT_PUBLIC_USE_FIREBASE_EMULATORS: "true",
    NEXT_PUBLIC_FIRESTORE_EMULATOR_HOST: "127.0.0.1:6104",

  assert.throws(

    FirebaseEnvError,
  );
  assert.throws(
    () =>
      readPublicFirebaseEnv({
        ...publicEnv,
        NEXT_PUBLIC_USE_FIREBASE_EMULATORS: "false",
      }),
    /only exists in the emulators/,
  );

    "env guards: non-demo refused, partial or malformed emulator hosts refused",
  );
}

/** Runs one cleanup step. A failure is logged, not thrown, so it can't mask the original error. */
async function cleanup(
  name: string,
  run: () => Promise<unknown>,
): Promise<void> {
  try {
    await run();
  } catch (error: unknown) {
    console.error(
      `not ok - cleanup ${name}:`,
      error instanceof Error ? error.message : error,
    );
  }
}

async function main(): Promise<void> {
  console.log(`# env file: ${envFile}`);
  checkGuards();

  const env = readServerFirebaseEnv();
  assert.equal(env.mode, "emulator");
  await assertReachable("Firestore", env.emulators.firestore);
  await assertReachable("Auth", env.emulators.auth);
  await assertReachable("Storage", env.emulators.storage);
  step(`emulator mode for ${env.projectId}, emulators reachable`);

  const nonce = randomUUID();
  const docRef = getAdminFirestore().collection("_smoke").doc(nonce);
  const file = getAdminStorage().bucket().file(`_smoke/${nonce}.txt`);
  const email = `smoke-${nonce}@example.test`;
  let uid: string | undefined;

  try {
    await docRef.set({ nonce, at: Date.now() });
    assert.equal((await docRef.get()).get("nonce"), nonce);
    step("Firestore write + read");

    uid = (await getAdminAuth().createUser({ email, password: `pw-${nonce}` }))
      .uid;
    assert.equal((await getAdminAuth().getUserByEmail(email)).uid, uid);
    step("Auth create user + lookup");

    await file.save(nonce, { contentType: "text/plain" });
    const [contents] = await file.download();
    assert.equal(contents.toString("utf8"), nonce);
    step("Storage upload + download");
  } finally {
    // Each step logs its own failure, so a cleanup error never hides the original one.
    await cleanup("Firestore doc", () => docRef.delete());
    const createdUid = uid; // a const keeps the narrowing inside the closure
    if (createdUid) {
      await cleanup("Auth user", () => getAdminAuth().deleteUser(createdUid));
    }
    await cleanup("Storage file", () => file.delete({ ignoreNotFound: true }));
  }

  assert.equal((await docRef.get()).exists, false);
  await assert.rejects(getAdminAuth().getUserByEmail(email), {
    code: "auth/user-not-found",
  });
  assert.equal((await file.exists())[0], false);
  step("cleanup verified");
}

// Explicit exit: firebase-admin keeps gRPC handles open after the last call.
main().then(
  () => process.exit(0),
  (error: unknown) => {
    console.error("not ok -", error instanceof Error ? error.message : error);
    process.exit(1);
  },
);
```

**scripts/check-client-bundle.mjs**
```js
// Fails if the client bundle (.next/static) contains server-only Firebase code or the name of
// any server-only env var. Run after `npm run build`: `npm run check:client-bundle`.
import { readdirSync, readFileSync, existsSync } from "node:fs";
import { join } from "node:path";

const STATIC_DIR = ".next/static";
if (!existsSync(STATIC_DIR)) {
  console.error(`${STATIC_DIR} not found. Run \`npm run build\` first.`);
  process.exit(1);
}

// Server-only packages that must never reach the browser.
const PACKAGE_MARKERS = [
  "firebase-admin",
  "google-auth-library",
  "@google-cloud/",
  "gcp-metadata",
];

// Every non-NEXT_PUBLIC_ variable named in .env.example (new ones are covered automatically).
const serverEnvNames = readFileSync(".env.example", "utf8")
  .split(/\r?\n/)
  .map((line) => /^\s*#?\s*([A-Z][A-Z0-9_]*)=/.exec(line)?.[1])
  .filter((name) => name !== undefined && !name.startsWith("NEXT_PUBLIC_"));
// Match the bare name only, not as the tail of a NEXT_PUBLIC_ name.
const envPattern = new RegExp(
  `(?<![A-Z0-9_])(${serverEnvNames.join("|")})(?![A-Z0-9_])`,
);

const files = readdirSync(STATIC_DIR, { recursive: true, withFileTypes: true })
  .filter(
    (entry) => entry.isFile() && /\.(js|mjs|css|map|json)$/.test(entry.name),
  )
  .map((entry) => join(entry.parentPath, entry.name));

const problems = [];
for (const file of files) {
  const text = readFileSync(file, "utf8");
  for (const marker of PACKAGE_MARKERS) {
    if (text.includes(marker)) problems.push(`${file}: contains "${marker}"`);
  }
  const envHit = envPattern.exec(text);
  if (envHit) problems.push(`${file}: contains server env name "${envHit[1]}"`);
}

if (problems.length > 0) {
  console.error(`Client bundle check FAILED:\n${problems.join("\n")}`);
  process.exit(1);
}
console.log(
  `Client bundle check passed: ${files.length} files, no server packages, ` +
    `no server env names (${serverEnvNames.join(", ")}).`,
);
```
