## 1. Decisions

### 1.1 Command and guards
- `npm run seed` = `tsx --conditions=react-server scripts/seed/index.ts`. `npm run seed -- --reset` clears first. Any other argument is refused. It loads `.env.local` if present, else `.env.example` (shell variables win), like `smoke:firebase`.
- **Emulators only.** A project ID that isn't `demo-*` is refused *before* the M1.3 guard, so `FIREBASE_ALLOW_NON_DEMO_PROJECT=true` doesn't help either. Then `readServerFirebaseEnv()` (M1.3) requires all three Admin emulator hosts. Then each of the three hosts must be loopback (`127.0.0.1`, `localhost` or `::1`; `assertLoopback`): the check reads only the string, so `firestore.googleapis.com:443` is refused with no DNS lookup and no connection. Then the local files are checked (§1.3), so a fresh clone gets its fix without starting the emulators. Then a 2 s TCP check of the Firestore and Storage emulators gives "not reachable … start `npm run emulators`" instead of the SDKs' endless retries. Admin init is `lib/firebase/admin` (emulator mode, no credential).
- It writes only `products/*`, `collections/*` and Storage `products/**`. It never touches users, orders, newsletterSignups or Auth.

### 1.2 Data
- **Source.** The catalog mapping that M1.4 wrote for the tests moves from `tests/unit/fixtures/catalog.ts` to `scripts/seed/catalog.ts`, unchanged apart from a few exports (§2 diff). Its 7 importers now import from there. Products: `parseProductInput` → `catalogProblems` (catalog plus fixtures, against the 6 collection slugs; any problem aborts the seed) → `deriveCatalog`. Collections: `parseCollectionInput`. Writes go through `adminCollections(db)` (the converters run the entity guards again).
- **Timestamps: deterministic, not server timestamps.** `createdAt = updatedAt = SEED_TIME` (`2026-10-01T00:00:00Z`). `publishedAt = SEED_TIME + sortOrder minutes` for published and archived products, and `null` for drafts, so "newest" (M3) sorts later-listed products first and differs from the default order. Why: with `serverTimestamp()`, every re-seed would change `updatedAt` and `publishedAt`, so the seed wouldn't be idempotent (the test compares whole dumps) and every build would bake different dates. That wouldn't break the cache mechanically (each build starts with an empty data cache), but it would make builds and screenshots non-reproducible. With fixed dates, a re-seed gives byte-identical documents and prerendered pages.
- **Batches.** `WriteBatch` in chunks of ≤500. Today that is 25 writes in one atomic batch, so products and collections appear together.
- **Idempotent.** `set()` replaces whole documents, so a field dropped from the catalog disappears. A document in `products`/`collections` that the seed doesn't write is **kept and listed** in the summary (it might be a dev's manual edit). `--reset` first runs `recursiveDelete` on both collections and `deleteFiles({ prefix: "products/" })` on Storage.
- **Fixtures: a separate seed-only file, `scripts/seed/fixtures.ts`, not `catalog.json`** (that file is design data). `fixture-draft-tin` (draft, a copy of Late Bloom) and `fixture-archived-bestseller` (archived, a copy of Midnight Balcony with the `bestseller` badge, so the bestseller query is tested against an unpublished bestseller). Each copies an approved product's copy, notes and variants verbatim, with its own slug and SKUs, sortOrder 900+ and a name suffix "(draft fixture)" / "(archived fixture)". The suffix is a technical label in emulator-only data, which the repositories never return. The product guard requires a catalog image, so their image refs point to `products/<fixture-slug>/cat-*.png`, but **no file is uploaded there**, and the seed deletes any file it finds (M1.5 §1: a file under `products/` is public by exact path). Forward note for M7: an admin preview must handle a missing object.
- **Forward note for the production setup:** the seed refuses every non-demo project today. A future production seed (only after the user approves production) must **exclude `scripts/seed/fixtures.ts`**: the "(draft fixture)" / "(archived fixture)" documents must never reach a real project.

### 1.5 Next data cache
After writing, the seed deletes `.next/cache/fetch-cache` and `.next/dev/cache/fetch-cache`. When an object was uploaded (or after `--reset`), it also deletes `.next/cache/images` and `.next/dev/cache/images`. **Verified: a running `next dev` also holds entries in memory** (`FileSystemCache.memoryCache`). After a re-seed with a changed name, a plain reload was stale. A hard reload (`Cache-Control: no-cache`) was fresh, and so were later plain reloads. So: with `next dev` running, hard-reload once after seeding. The `clear-data-cache.mjs` comment says so (§2).

### `scripts/seed/index.ts` (new)

```ts
/**
 * `npm run seed [-- --reset]`: seeds the Firestore and Storage emulators with the catalog
 * (design/tech/M1.8-seed.md). Emulators only: a non-demo project, a missing emulator host
 * (lib/firebase/env.server.ts) or one that isn't loopback is refused, and so is
 * FIREBASE_ALLOW_NON_DEMO_PROJECT=true.
 * Dev: `npm run emulators` in one terminal, then `npm run seed` in another.
 * Loads .env.local if present, else .env.example (variables already set in the shell win).
 */
import { existsSync } from "node:fs";

import { formatSummary, runSeed } from "./seed";

const USAGE = "usage: npm run seed [-- --reset]";

async function main(): Promise<void> {
  const args = process.argv.slice(2);
  const unknown = args.filter((a) => a !== "--reset");
  if (unknown.length > 0) {
    throw new Error(`unknown argument ${unknown.join(" ")}\n${USAGE}`);
  }
  const envFile = existsSync(".env.local") ? ".env.local" : ".env.example";
  process.loadEnvFile(envFile);
  console.log(`# env file: ${envFile}`);
  const summary = await runSeed({ reset: args.includes("--reset") });
  console.log(formatSummary(summary));
}

// Explicit exit: firebase-admin keeps gRPC handles open after the last call.
main().then(
  () => process.exit(0),
  (error: unknown) => {
    console.error(
      "seed failed -",
      error instanceof Error ? error.message : error,
    );
    process.exit(1);
  },
);
```

  const fixtures = fixtureProductInputs(catalog);
  const collectionInputs = json.collections.map((c) =>
    parseCollectionInput(toCollectionInputRaw(c, json)),
  );
  const problems = catalogProblems(
    [...catalog, ...fixtures],
    collectionInputs.map((c) => c.slug),
  );
  if (problems.length > 0) {
    throw new Error(`catalog problems:\n  ${problems.join("\n  ")}`);
  }
  const products: Product[] = deriveCatalog([...catalog, ...fixtures]).map(
    (p) => ({
      ...p,
      createdAt: SEED_TIME,
      updatedAt: SEED_TIME,
      // "Newest" sort: a later sortOrder was published later. Drafts were never published.
      publishedAt:
        p.status === "draft"
          ? null
          : new Date(SEED_TIME.getTime() + p.sortOrder * MINUTE),
    }),
  );
  const collections: Collection[] = collectionInputs.map((c) => ({
    ...c,
    createdAt: SEED_TIME,
    updatedAt: SEED_TIME,
  }));
  return {
    products,
    collections,
    // Fixtures are left out on purpose: no file under their folders.
    uploads: storageUploads(json, catalog),
    publicFiles: publicExports(json).exports.map((e) => ({
      id: e.id,
      file: e.target,
      ...e.size,
    })),
    flagged: [...json.statuses]
      .filter(([, status]) => status === "flagged")
      .map(([id]) => id)
      .sort(),
    json,
  };
}

/**
 * Every file problem (missing, wrong size, under the minimum), before anything is written. With
 * no originals (a fresh clone: assets/ is not in git) it is one problem that says how to fix it.
 */
export function seedFileProblems(data: SeedData): string[] {
  const noOriginals = missingOriginalsMessage(data.json);
  if (noOriginals) return [noOriginals];
  const files = new Map<string, string | null>();
  for (const u of data.uploads) {
    files.set(
      u.file,
      fileProblem(u.file, u.size, minimumSize(data.json, u.id)),
    );
  }
  for (const p of data.publicFiles) {
    files.set(p.file, fileProblem(p.file, p, minimumSize(data.json, p.id)));
  }
  return [...files.values()].filter((p): p is string => p !== null);
}

/** parseHostPort (M1.3) accepts only IPv4 addresses and host names; ::1 is listed for completeness. */
const LOOPBACK_HOSTS = new Set(["127.0.0.1", "localhost", "::1", "[::1]"]);

/**
 * The seed talks only to emulators on this machine: a host that isn't loopback (for example
 * firestore.googleapis.com:443) is refused from the string alone, before any DNS lookup.
 */
export function assertLoopback(name: string, { host, port }: HostPort): void {
  if (!LOOPBACK_HOSTS.has(host.toLowerCase())) {
    throw new Error(
      `${name} emulator host "${host}:${port}" is not a loopback address (127.0.0.1, localhost or ::1); npm run seed writes to local emulators only.`,
    );
  }
}

/** Fails fast; otherwise the SDKs keep retrying against a closed port. */
export function assertReachable(
  name: string,
  { host, port }: HostPort,
): Promise<void> {
  return new Promise((resolve, reject) => {
    const socket = connect({ host, port, timeout: 2000 });
    const fail = (): void => {
      socket.destroy();
      reject(
        new Error(
          `${name} emulator is not reachable on ${host}:${port}. Start it with \`npm run emulators\`.`,
        ),
      );
    };
    socket.once("connect", () => {
      socket.end();
      resolve();
    });
    socket.once("timeout", fail);
    socket.once("error", fail);
  });
}

const md5Base64 = (bytes: Buffer) =>
  createHash("md5").update(bytes).digest("base64");

async function uploadIfChanged(
  bucket: Bucket,
  upload: StorageUpload,
): Promise<"uploaded" | "unchanged"> {
  const bytes = readFileSync(upload.file);
  const file = bucket.file(upload.storagePath);
  const [exists] = await file.exists();
  if (exists) {
    const [meta] = await file.getMetadata();
    if (
      meta.md5Hash === md5Base64(bytes) &&
      meta.contentType === upload.contentType &&
      meta.cacheControl === OBJECT_CACHE_CONTROL
    ) {
      return "unchanged";
    }
  }
  await file.save(bytes, {
    resumable: false,
    contentType: upload.contentType,
    metadata: { cacheControl: OBJECT_CACHE_CONTROL },
  });
  return "uploaded";
}

/** Runs `task` over `items`, at most `limit` at a time. */
async function inPool<T, R>(
  items: readonly T[],
  limit: number,
  task: (item: T) => Promise<R>,
): Promise<R[]> {
  const results: R[] = new Array(items.length);
  let next = 0;
  const worker = async () => {
    while (next < items.length) {
      const index = next++;
      results[index] = await task(items[index]!);
    }
  };
  await Promise.all(
    Array.from({ length: Math.min(limit, items.length) }, worker),
  );
  return results;
}

  // Checked before the M1.3 guard, whose message offers FIREBASE_ALLOW_NON_DEMO_PROJECT: the
  // seed ignores that switch and never runs against a real project.
  const projectId = process.env.NEXT_PUBLIC_FIREBASE_PROJECT_ID?.trim() ?? "";
  if (!isDemoProjectId(projectId)) {
    throw new Error(
      `npm run seed writes to the emulators only; refusing non-demo project "${projectId || "(unset)"}".`,
    );
  }
  const env = readServerFirebaseEnv();
  if (env.mode !== "emulator") throw new Error("unreachable: demo project"); // narrows env
  assertLoopback("Firestore", env.emulators.firestore);
  assertLoopback("Auth", env.emulators.auth);
  assertLoopback("Storage", env.emulators.storage);

  // Local files next, so a fresh clone (no assets/) gets the fix without starting the emulators.
  const data = buildSeedData();
  const noOriginals = missingOriginalsMessage(data.json);
  if (noOriginals) throw new Error(noOriginals);
  const problems = seedFileProblems(data);
  if (problems.length > 0) {
    throw new Error(
      `image files are missing or the wrong size (run \`npm run images:build\`):\n  ${problems.join("\n  ")}`,
    );
  }

  await assertReachable("Firestore", env.emulators.firestore);
  await assertReachable("Storage", env.emulators.storage);

  const db = getAdminFirestore();
  const bucket = getAdminStorage().bucket();
  const refs = adminCollections(db);

  if (options.reset) {
    await db.recursiveDelete(db.collection(COLLECTIONS.products));
    await db.recursiveDelete(db.collection(COLLECTIONS.collections));
    await bucket.deleteFiles({ prefix: "products/" });
  }

  type Write = (batch: WriteBatch) => void;
  const writes: Write[] = [
    ...data.products.map<Write>(
      (p) => (b) => b.set(refs.products.doc(p.slug), p),
    ),
    ...data.collections.map<Write>(
      (c) => (b) => b.set(refs.collections.doc(c.slug), c),
    ),
  ];
  for (let i = 0; i < writes.length; i += BATCH_LIMIT) {
    const batch = db.batch();
    for (const write of writes.slice(i, i + BATCH_LIMIT)) write(batch);
    await batch.commit();
  }

  const seeded = new Set([
    ...data.products.map((p) => `${COLLECTIONS.products}/${p.slug}`),
    ...data.collections.map((c) => `${COLLECTIONS.collections}/${c.slug}`),
  ]);
  const strayDocuments: string[] = [];
  for (const name of [COLLECTIONS.products, COLLECTIONS.collections]) {
    for (const ref of await db.collection(name).listDocuments()) {
      if (!seeded.has(ref.path)) strayDocuments.push(ref.path);
    }
  }

  const results = await inPool(data.uploads, UPLOAD_CONCURRENCY, (u) =>
    uploadIfChanged(bucket, u),
  );
  let fixtureFilesRemoved = 0;
  for (const f of FIXTURES) {
    const [files] = await bucket.getFiles({ prefix: `products/${f.slug}/` });
    for (const file of files) await file.delete({ ignoreNotFound: true });
    fixtureFilesRemoved += files.length;
  }
  const uploaded = results.filter((r) => r === "uploaded").length;

  const cacheCleared: string[] = [];
  if (options.clearCache !== false) {
    const root = options.root ?? process.cwd();
    clearDirs(root, DATA_CACHE_DIRS);
    cacheCleared.push(...DATA_CACHE_DIRS);
    if (uploaded > 0 || options.reset) {
      clearDirs(root, IMAGE_CACHE_DIRS);
      cacheCleared.push(...IMAGE_CACHE_DIRS);
    }
  }

  const count = (status: Product["status"]) =>
    data.products.filter((p) => p.status === status).length;
  return {
    projectId: env.projectId,
    reset: options.reset === true,
    products: {
      published: count("published"),
      draft: count("draft"),
      archived: count("archived"),
    },
    collections: data.collections.length,
    objects: {
      uploaded,
      unchanged: results.length - uploaded,
      fixtureFilesRemoved,
    },
    strayDocuments,
    publicFiles: data.publicFiles.length,
    flagged: data.flagged,
    cacheCleared,
    ms: Date.now() - started,
  };
}

  expected: PixelSize,
  minimum: PixelSize,
): string | null {
  if (!existsSync(file)) return `${file}: missing`;
  let actual: PixelSize;
  try {
    actual = fileImageSize(file);

    return `${file}: ${error instanceof Error ? error.message : String(error)}`;

    return `${file}: ${actual.width} × ${actual.height} is under the minimum ${minimum.width} × ${minimum.height}`;
  }
  return null;
}

import { openSync, readSync, closeSync } from "node:fs";

/**
 * Pixel size from an image file's own header, with no image library (M1.4 §1 Images). The seed
 * and the asset step compare it with the size the catalog mapping derives from manifest.json.
 */
export type PixelSize = { width: number; height: number };

const PNG_SIGNATURE = Buffer.from([
  0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a,
]);

/** PNG: the IHDR chunk comes first; width and height are big-endian uint32 at bytes 16–23. */
export function pngSize(head: Buffer): PixelSize {
  if (
    head.length < 24 ||
    !head.subarray(0, 8).equals(PNG_SIGNATURE) ||
    head.toString("latin1", 12, 16) !== "IHDR"
  ) {
    throw new Error("not a PNG (no signature or IHDR)");
  }
  return { width: head.readUInt32BE(16), height: head.readUInt32BE(20) };
}

/** SOF0–SOF15 except DHT (C4), JPG (C8) and DAC (CC): the frame header holds the size. */
const isSof = (marker: number) =>
  marker >= 0xc0 && marker <= 0xcf && ![0xc4, 0xc8, 0xcc].includes(marker);

/**
 * JPEG: walk the marker segments from SOI to the first SOF; after the marker come the segment
 * length (2), precision (1), then height and width as big-endian uint16.
 */
export function jpegSize(data: Buffer): PixelSize {
  if (data.length < 4 || data[0] !== 0xff || data[1] !== 0xd8) {
    throw new Error("not a JPEG (no SOI)");
  }
  let offset = 2;
  while (offset + 4 <= data.length) {
    if (data[offset] !== 0xff) throw new Error("JPEG: bad marker");
    const marker = data[offset + 1]!;
    if (marker === 0xff) {
      offset += 1; // fill byte
      continue;
    }
    if (marker === 0xd9 || marker === 0xda) break; // EOI or SOS before any SOF
    const length = data.readUInt16BE(offset + 2);
    if (isSof(marker)) {
      if (offset + 9 > data.length) break;
      return {
        height: data.readUInt16BE(offset + 5),
        width: data.readUInt16BE(offset + 7),
      };
    }
    offset += 2 + length;
  }
  throw new Error("JPEG: no SOF segment in the header");
}

/** Reads only the first bytes of a file (the PNG IHDR, or the JPEG segments before SOF). */
export function fileImageSize(file: string, headBytes = 256 * 1024): PixelSize {
  const fd = openSync(file, "r");
  try {
    const head = Buffer.alloc(headBytes);
    const read = readSync(fd, head, 0, headBytes, 0);
    const bytes = head.subarray(0, read);
    return file.endsWith(".png") ? pngSize(bytes) : jpegSize(bytes);
  } finally {
    closeSync(fd);
  }
}

function pngHead(width: number, height: number): Buffer {
  const b = Buffer.alloc(33);
  Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]).copy(b, 0);
  b.writeUInt32BE(13, 8);
  b.write("IHDR", 12, "latin1");
  b.writeUInt32BE(width, 16);

}

/** SOI, an APP0 segment, then a SOF segment (marker C0 baseline or C2 progressive). */
function jpegHead(marker: number, width: number, height: number): Buffer {
  const app0 = Buffer.from([0xff, 0xe0, 0x00, 0x06, 0x4a, 0x46, 0x49, 0x46]);

  sof.writeUInt8(8, 4);
  sof.writeUInt16BE(height, 5);
  sof.writeUInt16BE(width, 7);
  return Buffer.concat([Buffer.from([0xff, 0xd8]), app0, sof]);
}
