## 1. Decisions

1. **`SiteFooter` is a Server Component built only from the registry** (`components/layout/SiteFooter.tsx`, replacing the M1.13 placeholder). Explore and Help come from `footerGroup("explore" | "help")` (Help's account-slot rule lives in the helper, footer.md §3.2.1), Legal from `footerGroup("legal")`, "Our collections" from preview data only (M3.7 wires `getCollections()` behind `features["collection-pages"]`; **M1.17 reads no data**). A group, nav, list or slot with nothing to show is not rendered. With none of them the footer renders the **minimal composition** (§4.2: centred wordmark, brand line with crescent, 20rem starlight rule, "© {year} Starflames"); otherwise the **standard composition** (§4.3). The switch is automatic. On every public route today: **zero links, no headings, no lists, no navs, nothing focusable.**
2. **Layout (Tailwind, no new CSS).** `footer`: `relative z-(--z-content) bg-bg-sunken`, padding top 48 / 64 / 80 / 96 (`pt-12 md:pt-16 lg:pt-20 xl:pt-24`), bottom `calc(2rem + env(safe-area-inset-bottom, 0px))`, from lg `calc(2.5rem + …)`, `print:break-inside-avoid` (§7.4's optional rule, taken). Content in `page-container`. Main row: flex column, gap 40 / 48 (md); from lg a 12-column grid on `--grid-gap` (brand cols 1–4, nav cols 5–12). Brand block: column, wordmark → 16 → brand line, then 24 → socials; at md a row (`justify-between`, `items-end`); column again from lg. The Footer nav's own grid: 4 / 8 columns, `gap-x-(--grid-gap)`, 32px rows; spans Explore 2 / 3 / 2, Our collections 2 / 3 / 3, Help 2 / 2 / 3 (base / md / lg+), auto-placed, `min-w-0`. Group: `h2` (`type-h4`, text-primary, `id="footer-{group}"`) → 8 → `ul aria-labelledby`. Rule: 1px `--gradient-starlight-rule`, 48 above (64 from lg), full width (standard) or `min(100%, 20rem)` centred (minimal), `aria-hidden` + `data-decorative`. Legal row: 24 below the rule; column with 8px gap at base, from md a wrapping row (`justify-between`, `items-center`); Legal links `gap-x-6`. Measured minimal height: **251px at 390, 334px at 1440** (spec: 251 / 334–335).
3. **Links: `NavLink` gains `footer` and `legal` variants** (`components/layout/header/NavLink.tsx`). Same state recipe as the bar (text-secondary; hover text-primary + 1px currentColor underline; current text-primary + 2px gold-300 underline; offset **0.4em**; visited = default), as an `inline-flex` 44 × 44 minimum row with no padding (text starts on the column edge, labels may wrap); `footer` is `type-nav`, `legal` `type-body-sm`. **Context by variant:** React contexts are invariant, so a `Record<variant, Context>` map can't hold both; NavLink reads **both** `HeaderPreviewContext` and `FooterPreviewContext` every render (hooks can't be conditional) and picks one with a variant → `"header" | "footer"` map. `peers` = every footer href (groups + legal), so `/collections/moonlit-terrace` marks Moonlit Terrace, not Collections. Public routes: `next/link` (server-rendered anchors, no JS needed); preview: plain `<a>`.
4. **`preview` is an object, not a boolean** (footer.md §11.1 leaves names to tech-agent): `SiteFooter preview={FOOTER_PREVIEW}` where `FooterPreviewData = { social, collections, slot }`. It turns on `{ preview: true }` for the helpers and carries the data that doesn't exist yet, so the `https://example.com/` placeholders and the catalog import live only in `app/dev/footer/preview-data.tsx` (§11.4), and the **`FooterSlotOutline` element is passed in by the dev page**: a Server Component's client imports join the route's chunk whether rendered or not (M1.15 finding), so importing the outline in `SiteFooter` would ship it on every public route. Measured: it is only in the `/dev/footer` chunk.
5. **Preview state** (footer.md §3.6, same pattern as `/dev/header`): `components/layout/footer/preview-context.ts` (`currentPath`, `showSlot` + setters, default `null`); `app/dev/footer/FooterPreviewProvider.tsx` renders only the provider and wraps `<main>` and `<SiteFooter preview>` (both stay direct children of `<body>`, asserted); `FooterPreviewControls` (client, in main) writes it: "Current page" (None, then every footer target in footer order; the options are built on the server and passed as props, so the catalog JSON never reaches the client) and "Show the reserved newsletter space". `FooterSlotOutline` (client leaf, `components/layout/footer/`) renders the dashed `border-divider` box at the M2.6 budget (`min-h-80`, `md:min-h-48`), the caption in `type-caption` text-muted, then the slot's starlight rule with 48 above and below, all inside one `div[data-footer-slot][data-print="hide"]` whose `hidden` follows the checkbox (`hidden` in the server HTML). `/dev/footer/minimal` has no provider and no controls and renders the exact public footer (its `outerHTML` equals `/`'s, asserted). Both pages share `FooterPreviewIntro` (h1 "Footer preview", the §9.1 intro, the "Footer state" pair "Full" / "Minimal (as shipped in M1.17)" with `aria-current`, `next/link` since both routes exist; a labelled list, not a `<nav>`, so the page adds no landmark whose name contains "Footer"). Both pages are static, gated by `requireDevPages()` in the page and `generateMetadata`; no `searchParams`.
6. **Social links** (`lib/site/social.ts`: `{ instagram: null, pinterest: null }`): a link renders only when its URL is set; the list (`ul aria-label="Starflames on social media"`, `data-print="hide"`, `gap-2`) only when one does, so **hidden in M1.17**. Each link: plain `<a rel="me">` (no `target`, no prefetch), `aria-label` "Starflames on Instagram" / "… on Pinterest", 44 × 44 `rounded-pill` with a 1px transparent border → gold-300 (`link`) on hover and press (`transition-colors`), 24px glyph scaled by `--motion-scale-press` on press. **Glyphs** (`components/icons/instagram.tsx`, `pinterest.tsx`): the platforms' marks with their path data, viewBox and transform copied by script (token-for-token equal, whitespace collapsed; never redrawn), `fill="#FFFFFF"` on the `<svg>` (the brand-mandated literal), `aria-hidden`, `focusable="false"`, and `forced-colors:fill-current`, so only under forced colors the fill follows `currentColor` (measured: the link's LinkText colour). Sources and licensing: §4 items 1–2.
7. **Print and forced colors need no `globals.css` change.** The existing print rule (`[data-print="hide"] { display: none !important }`, plus `[data-decorative]`) covers the Footer nav, the Legal nav, the social list and the slot; the crescent and rules are `data-decorative`. Forced colors: `[data-decorative]` is already removed; the transparent social borders become visible system-colour borders by themselves; the current underline survives. The glyph rule is the utility in item 6. **`app/globals.css` is unchanged.**

  href: string;
  label: string;
  variant: NavLinkVariant;

  peers: readonly string[];

  preview?: boolean;

  href,
  label,
  variant,
  peers,
  preview = false,
}: NavLinkProps) {

  // variant picks one. Each is null without its provider.

    PREVIEW_CONTEXT[variant] === "footer" ? footerPreview : headerPreview;

    href,
    className: CLASS[variant],

    </>
  );
  return preview ? (
    <a {...props}>{content}</a>
  ) : (
    <Link {...props}>{content}</Link>
  );

 * `sign-in` if live, else null; never both (footer.md §3.2.1). Pure, so the rule

 */
export function footerAccountSlot(
  entries: readonly RouteEntry[],
  options: RegistryOptions = {},
): RouteEntry | null {
  for (const key of ACCOUNT_SLOT) {

  group: FooterGroup,
  options: RegistryOptions = {},

    if (slot) rows.push(slot);
  }
  return rows;
}

/**
 * The most specific href that matches the path: the path itself, or a parent
 * of it (`/collections/moonlit-terrace` matches `/collections`). Only one link
 * of a set is current at a time (header.md §7.1).
 */
export function currentHref(
  pathname: string | null,
  hrefs: readonly string[],
): string | null {
  if (!pathname) return null;
  let best: string | null = null;
  for (const href of hrefs) {
    const matches = pathname === href || pathname.startsWith(`${href}/`);
    if (matches && (best === null || href.length > best.length)) best = href;
  }
  return best;
}
