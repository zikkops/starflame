## 1. Decisions

1. **Files** (starfield.md §14.1). `components/starfield/starfield-data.ts` (pure, no imports at all, so Node tests import it; `server-only` is only in the layer), `StarfieldLayer.tsx` (Server, `import "server-only"`, computes `buildStarfield()` once at module scope), `StarfieldIsland.tsx` (client loader, renders `null`), `starfield-motion.ts` (the lazy chunk; imports only `lib/motion/tokens.ts`), CSS as **section 10 of `app/globals.css`** (inside `@layer components`, keyframes after it). `StarfieldSlot` renders layer + island and, for `preview.still`, `data-starfield-state="static"` on the server; `SiteShell` takes `starfieldPreview`. `Container` gets `data-open-sky` (the prose wrapper is deliberately **not** marked: conservative). `Section` already sets `data-band`.
2. **Deterministic sky** (§14.3). Seed `20261009`, mulberry32, R2 positions plus ±1% seeded jitter, rounded to 0.1%, kept within 1–99%, rejected inside the 2% × 3% separation box. Ranks 0–35 base, 36–71 md, 72–95 lg, 96–127 xl. Twinkle: ranks with `rank % 5 === 2`; a rank whose star lies in a backing's exclusion area passes its turn to the next clear rank of its tier (the generator throws if a tier ends short). The exclusion area for a pair is the union of the backing's sky-% boxes over every integer width from the **higher of the two tiers'** minimum to 3840px, at that tier's minimum sky height (where the box is tallest in %), widened 1%. Edge marks: per side 6 bright dots (3/4/5/6 by tier), one dot per side twinkles; four-point stars start + end at base, end at lg, start at xl. **The upper four-point stars sit at y 6–8% (start) and 8–10% (end)**, not anywhere in the upper half: at 15–40% they touched the Drift chain (centred at y 30%, 100px tall) at 1920 (seen in the wide shot); 6–10% keeps the 44px glow clear of Drift in every xl sky, and the split keeps the pair from sitting level (changelog 4) (data test 4 checks heights 360–2160). Bright dots are star-core.
3. **Markup** (§14.2, budget 16KB raw). Paint order: field SVG (still dim circles, grouped tier → colour + level, `data-sf-min` on the tier group), `div[data-sf-twinkles][data-sf-dim]` holding the 26 dim twinkle spans (one `data-sf-dim` wrapper instead of one per span), the column (`data-sf-column data-sf-dim`, backings at `clamp()` positions, bg-page, 6px padding), then the two edge zones (dots SVG, twinkle spans, the `FourPointStarIcon` from `components/icons/glyphs.tsx` inside four-point spans, the Drift div). Constellation lines are one `<path>` per pattern whose segments are **pulled in by 3px + the 0.5px round cap** at each end (`lineSegments()` in the data module, tested) instead of an SVG mask: same 3px gap, no mask rendering, fewer bytes. Each span carries only `left`, `top`, `--sf-hi`, `--sf-dur`, `--sf-delay`; CSS derives `--sf-lo` (0.5 × hi dim, 0.6 × hi edge) and the still value `opacity: calc((lo + hi) / 2)`. Numbers are written in their shortest form (`.12`). Measured: **15,485 B raw, 2,612 B gz** (`outerHTML` at 1440).
4. **Twinkle keyframes read `var(--sf-lo)` / `var(--sf-hi)` and are composited** (CDP probe and test 15: every span has its own `ActiveOpacityAnimation` layer), so the literal-keyframes fallback is not needed.
5. **Zones in CSS** exactly as §3.1 (`--sf-band`, `--sf-edge-start/end` with `100%` resolved where used, i.e. against the sky). The slot's width equals the body's even with the stable scrollbar gutter (1425 at 1440 in headless Chromium), so zones line up with the Container. Tiers: `[data-sf-min]` hidden below md/lg/xl and under `(max-height: 28rem)`; four-point size `--sf-fp` 8/10/12px, 8px when short. Minimum sky: `@container sf-sky (width < 320px) or (height < 120px)` hides `[data-sf-dim]`. Zones are `inline-size` containers: glow (`shadow-glow-starlight`, round span) from 56px, Drift from 120px. `prefers-contrast: more` hides `[data-sf-dim]` and stops the twinkle; `static`, `html[data-motion="off"]` → `animation: none`; `paused` → `animation-play-state: paused`. Forced colours and print use the existing `[data-decorative]` rules.
6. **Loader** (`StarfieldIsland`): after `load` (or at once if already complete), `requestIdleCallback(…, { timeout: 2000 })`, else `setTimeout(…, 1500)`; then `import("./starfield-motion")`, a separate chunk. `usePathname()` changes call `onRouteChange()`; unmount calls `destroy()`.
7. **Motion module** (§4.5, §6). State = `static` (still preview, `data-motion="off"`, reduced motion, forced colours, more contrast) › `paused` (hidden, no plain band in view, 60s without scroll/wheel/touchmove/pointerdown/keydown) › `animating`. ## 3. PUSHBACK (to PROGRESS.md under M1.19, for design)

**Problem.** starfield.md §9 / test 15: "≤ 16ms on mobile-390 under 4× CPU throttling, never a long task", with all three paths' hit tests in one `sf-attempt`. CDP's 4× throttle is not linear for this workload: `elementFromPoint` runs ~15× slower (plain script ~5×). One path of 135 hit tests already takes 17–46ms under it, so ≤ 16ms can't be met by any implementation of the 5-line, 8px grid; three paths in one task took 22–46ms, one task from a long task. Separately, a 4ms *maximum* is not stable on a shared machine: the same desktop check ran 1.3–5.8ms per path under parallel workers.

**Proposed alternative (prototyped).** (1) Each path's check runs in its own task; `sf-attempt` measures one task (one path, or one of the demo's three checks); the demo launches after its third check. (2) Test 15 runs unthrottled in both projects (both run Chromium; mobile-390 emulates the viewport, not the CPU): every task ≤ 16ms (one frame), no long task overlapping an attempt, and **median ≤ 4ms**, asserted in a serial run (`--workers=1`, the review measurement); parallel runs assert only the frame and long-task budgets. (3) The 4× throttle figures are reported in the build review, not asserted. The 5-line, 8px grid is unchanged.

  return p.lines.map(([a, b]) => {
    const [x1, y1] = p.stars[a]!;
    const [x2, y2] = p.stars[b]!;
    const len = Math.hypot(x2 - x1, y2 - y1);
    const ux = ((x2 - x1) / len) * (LINE_GAP + LINE_CAP);
    const uy = ((y2 - y1) / len) * (LINE_GAP + LINE_CAP);
    return [x1 + ux, y1 + uy, x2 - ux, y2 - uy];
  });
}

/** Dim constellations: tier and anchor in % of the content column / sky (§4.3). */
export type DimConstellation = {
  pattern: Pattern;
  tier: Tier;
  ax: number;
  ay: number;
};
/** Backing = pattern box + 6px on every side (§4.3). */
export const BACKING_PAD = 6;
export const DIM_CONSTELLATIONS: readonly DimConstellation[] = [
  { pattern: PATTERNS.wick, tier: "base", ax: 58, ay: 62 },
  { pattern: PATTERNS.ribbon, tier: "md", ax: 12, ay: 24 },
  { pattern: PATTERNS.sprig, tier: "lg", ax: 74, ay: 40 },
];
export const backingSize = (p: Pattern): { w: number; h: number } => ({
  w: p.w + 2 * BACKING_PAD,
  h: p.h + 2 * BACKING_PAD,

/* ── Geometry (§3.1, §4.3), as functions of the viewport width, no insets ── */

/** --gutter per breakpoint (tokens.md §9): md 768, lg 1024, xl 1440. */
export function gutter(width: number): number {
  if (width >= 1440) return 80;
  if (width >= 1024) return 40;
  if (width >= 768) return 32;
  return 20;
}
/** The tier a viewport shows (short viewports show only the base tier). */
export function tierAt(width: number, height: number): Tier {
  if (height <= 448) return "base";
  if (width >= 1440) return "xl";
  if (width >= 1024) return "lg";
  if (width >= 768) return "md";
  return "base";
}
/** Each edge zone's width: outside the Container's content box, less 8px. */
export function edgeWidth(width: number): number {
  const g = gutter(width);
  return Math.max(0, (width - 1280 - 2 * g) / 2) + g - 8;
}
export type Rect = { left: number; top: number; right: number; bottom: number };
/** A dim constellation's backing in px of a sky `width` × `height`. */
export function backingRect(
  c: DimConstellation,
  width: number,
  height: number,
): Rect {
  const edge = edgeWidth(width);
  const column = width - 2 * edge;
  const { w, h } = backingSize(c.pattern);
  const clamp = (v: number, max: number) => Math.min(Math.max(0, v), max);
  const left = edge + clamp((c.ax / 100) * column, column - w);
  const top = clamp((c.ay / 100) * height, height - h);
  return { left, top, right: left + w, bottom: top + h };
}
/**
 * The sky-% area a backing can cover next to a mark of `tier`: the union of its
 * rectangles over every integer width from the pair's minimum to 3840px, at the
 * pair's smallest sky (where the box is tallest in %), widened by 1% for the
 * span's own size (§14.3).
 */
function exclusion(tier: Tier, c: DimConstellation): Rect {
  const pair = TIER_MIN[maxTier(tier, c.tier)];
  const area: Rect = { left: 100, top: 100, right: 0, bottom: 0 };
  for (let w = pair.w; w <= MAX_WIDTH; w++) {
    const b = backingRect(c, w, pair.h);
    area.left = Math.min(area.left, (b.left / w) * 100 - 1);
    area.right = Math.max(area.right, (b.right / w) * 100 + 1);
    area.top = Math.min(area.top, (b.top / pair.h) * 100 - 1);
    area.bottom = Math.max(area.bottom, (b.bottom / pair.h) * 100 + 1);
  }
  return area;
}
const clearOf = (areas: readonly Rect[], x: number, y: number): boolean =>
  areas.every(
    (a) => x <= a.left || x >= a.right || y <= a.top || y >= a.bottom,
  );

/* ── Randomness ──────────────────────────────────────────────────────────── */

export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
const G = 1.32471795724474602596;
const frac = (v: number): number => v - Math.floor(v);
const round1 = (v: number): number => Math.round(v * 10) / 10;
const pick = <T>(rng: () => number, items: readonly T[]): T =>
  items[Math.floor(rng() * items.length)] as T;
const between = (rng: () => number, lo: number, hi: number): number =>
  lo + rng() * (hi - lo);
function weighted<T>(rng: () => number, table: readonly [T, number][]): T {
  let roll = rng();
  for (const [value, weight] of table) {
    if ((roll -= weight) < 0) return value;
  }
  return table[table.length - 1]![0];
}
const tierOfRank = (rank: number): Tier =>
  TIERS.find((tier) => rank < DIM_COUNT[tier]) ?? "xl";
function timing(rng: () => number): { dur: number; delay: number } {
  const dur = Math.round(between(rng, 3000, 6000));
  return { dur, delay: -Math.round(rng() * dur) };
}

/* ── The sky ─────────────────────────────────────────────────────────────── */

export type Starfield = {
  dim: DimStar[];
  edges: EdgeMark[];
};

function buildDim(rng: () => number): DimStar[] {
  const stars: DimStar[] = [];
  for (let n = 0; stars.length < DIM_COUNT.xl; n++) {
    // R2 sequence plus a seeded jitter of up to ±1%.
    const x = round1(frac(0.5 + n / G) * 100 + between(rng, -1, 1));
    const y = round1(frac(0.5 + n / (G * G)) * 100 + between(rng, -1, 1));
    if (x < 1 || x > 99 || y < 1 || y > 99) continue;
    if (
      stars.some((s) => Math.abs(s.x - x) < SEP_X && Math.abs(s.y - y) < SEP_Y)
    ) {
      continue;
    }
    const rank = stars.length;
    stars.push({
      rank,
      tier: tierOfRank(rank),
      x,
      y,
      r: weighted(rng, [
        [0.5, 0.6],
        [0.75, 0.3],
        [1, 0.1],
      ]),
      colour: weighted<Colour>(rng, [
        ["core", 0.7],
        ["violet", 0.15],
        ["gold", 0.1],
        ["rose", 0.05],
      ]),
      level: pick(rng, DIM_LEVELS),
      kind: "circle",
    });
  }
  // About one in five twinkles: ranks with rank % 5 === 2; one that falls under
  // a constellation backing passes its turn to the next clear rank of its tier.
  const areas = new Map(
    TIERS.map((tier) => [
      tier,
      DIM_CONSTELLATIONS.map((c) => exclusion(tier, c)),
    ]),
  );
  let owed = 0;
  for (const star of stars) {
    if (star.rank % 5 === 2) owed++;
    if (owed > 0 && clearOf(areas.get(star.tier) ?? [], star.x, star.y)) {
      owed--;
      star.kind = "twinkle";
      star.size = star.r > 0.5 ? 2 : 1;
      Object.assign(star, timing(rng));
    }
    if (star.rank === DIM_COUNT[star.tier] - 1 && owed > 0) {
      throw new Error(`starfield: tier ${star.tier} is short of twinkle stars`);
    }
  }
  return stars;
}

function buildEdges(rng: () => number): EdgeMark[] {
  const marks: EdgeMark[] = [];
  // Four-point stars: one upper per side from base; the lower end one at lg, the
  // lower start one at xl (§7). The upper ones sit above Drift (centred at y 30%,
  // 100px tall) with their 44px glow, even in the smallest xl sky (360px); the
  // two sides take different bands (start y 6-8%, end y 8-10%).
  const fourPoint: [Side, Tier, number, number][] = [
    ["start", "base", 6, 8],
    ["end", "base", 8, 10],
    ["end", "lg", 60, 85],
    ["start", "xl", 60, 85],
  ];
  for (const [side, tier, lo, hi] of fourPoint) {
    marks.push({
      side,
      tier,
      kind: "four-point",
      x: 50,
      y: round1(between(rng, lo, hi)),
      r: 0,
      level: FOUR_POINT_PEAK,
      twinkle: true,
      ...timing(rng),
    });
  }
  for (const side of ["start", "end"] as const) {
    const taken = marks.filter((m) => m.side === side).map((m) => m.y);
    for (let rank = 0; rank < BRIGHT_PER_SIDE.xl;) {
      const y = round1(between(rng, 5, 95));
      if (taken.some((t) => Math.abs(t - y) < 6)) continue;
      taken.push(y);
      const twinkle = rank === 0; // one bright dot per side twinkles
      marks.push({
        side,
        tier: TIERS.find((tier) => rank < BRIGHT_PER_SIDE[tier]) ?? "xl",
        kind: "dot",
        x: round1(between(rng, 25, 75)),
        y,
        r: twinkle ? 1 : pick(rng, [0.75, 1, 1.25]),
        level: pick(rng, BRIGHT_LEVELS),
        twinkle,
        ...(twinkle ? timing(rng) : {}),
      });
      rank++;
    }
  }
  return marks;
}

/** The whole sky as plain data. Same seed, same sky. */
export function buildStarfield(seed: number = STARFIELD_SEED): Starfield {
  const rng = mulberry32(seed);
  return { dim: buildDim(rng), edges: buildEdges(rng) };
}

type Attrs = Readonly<Record<string, string | number | undefined>>;

/** One element; attributes in order, undefined ones left out (as React does). */
function tag(name: string, attrs: Attrs, inner = ""): string {
  let open = `<${name}`;

    if (value === undefined) continue;

      throw new Error(`starfield: unexpected markup in ${name} ${key}`);
    }

  return `${open}>${inner}</${name}>`;
}

import type { StarfieldPreview } from "./starfield-data";

/**
 * The starfield's motion module (starfield.md §4.5, §6, §13.1), loaded by
 * StarfieldIsland after `load` plus idle. It owns the slot's state attribute
 * (animating / paused / static; the CSS twinkle follows it), and the falling
 * star: a WAAPI streak through verified open sky, appended to the slot (a
 * sibling of main), cancelled at once by scroll, input, navigation or any
 * change in main. It writes nothing inside main, ever.
 */

export type StarfieldController = {
  onRouteChange(): void;
  destroy(): void;
};

type State = "animating" | "paused" | "static";
type Skip = "edge" | "null" | "text";
type Path = {
  /** The head at the start, in viewport px. */
  x: number;
  y: number;
  /** Unit direction (down and toward one side). */
  dx: number;
  dy: number;
  travel: number;
  trail: number;
  /** Corridor half-width. */
  half: number;
  thick: number;
};
type Flight = { el: HTMLElement; anim: Animation; observers: Observer[] };
type Observer = { disconnect(): void };

const IDLE_MS = 60_000;
const SCROLL_LOCK_MS = 1000;
const MAX_STREAKS = 6;
const DEMO_EVERY_MS = 3000;
/** What a sample may hit: open sky (§4.5 check 3). */
const OPEN_SKY = 'html,body,main#main,[data-band="plain"],[data-open-sky]';
const INPUTS = ["scroll", "wheel", "touchmove", "pointerdown", "keydown"];
const SCROLLS = ["scroll", "wheel", "touchmove"];

const rand = (lo: number, hi: number): number => lo + Math.random() * (hi - lo);

export function startStarfield(
  slot: HTMLElement,
  preview: StarfieldPreview = {},
): StarfieldController {
  const html = document.documentElement;
  const sky = slot.querySelector<HTMLElement>("[data-sf-sky]");
  const mode = preview.streak ?? "on";
  const demo = mode === "demo" || mode === "demo-blocked";
  const prefs = [
    "(prefers-reduced-motion: reduce)",
    "(forced-colors: active)",
    "(prefers-contrast: more)",
  ].map((q) => matchMedia(q));
  const md = matchMedia("(min-width: 48rem)");
  const short = matchMedia("(max-height: 28rem)");
  // Each changes --header-h or the tier, and so the band (§6.2).
  const bandQueries = [
    md,
    matchMedia("(min-width: 64rem)"),
    matchMedia("(min-width: 90rem)"),
    short,
  ];

  let state: State | undefined;
  let visible = new Set<Element>();
  let io: IntersectionObserver | undefined;
  let band = -1;
  let lastInput = performance.now();
  let lastScroll = -Infinity;
  let timer = 0;
  let idleTimer = 0;
  let count = 0;
  let started = false;
  let flight: Flight | undefined;

  const attr = (name: string, value: string) => slot.setAttribute(name, value);
  attr("data-sf-streaks", "0");

  function compute(): State {
    if (
      preview.still ||
      html.dataset.motion === "off" ||
      prefs.some((q) => q.matches)
    ) {
      return "static";
    }
    if (
      document.hidden ||
      visible.size === 0 ||
      performance.now() - lastInput >= IDLE_MS
    ) {
      return "paused";
    }
    return "animating";
  }

  function update(): void {
    const next = compute();
    clearTimeout(idleTimer);
    if (next === "animating") {
      idleTimer = window.setTimeout(
        update,
        lastInput + IDLE_MS - performance.now(),
      );
    }
    if (next === state) return;
    state = next;
    attr("data-starfield-state", next);
    clearTimeout(timer);
    if (next === "animating") {
      // Afresh: leaving `paused` never fires a burst of missed streaks.
      schedule(demo ? 0 : started ? rand(10e3, 16e3) : rand(6e3, 12e3));
    } else {
      cancel();
    }
  }

  function schedule(delay: number): void {
    if (mode === "off" || (!demo && count >= MAX_STREAKS)) return;
    timer = window.setTimeout(attempt, delay);
  }

  /* ── Paths and the corridor check (§4.5, §13.3) ── */

  const wide = (): boolean => md.matches && !short.matches;

  /** Where samples may lie: inside the layer and the viewport, 16px from its
      edges, 24px below the header band. */
  function bounds() {
    const layer = slot.getBoundingClientRect();
    const top = sky ? sky.getBoundingClientRect().top : layer.top;
    return {
      left: Math.max(layer.left, 0) + 16,
      top: top + 24,
      right: Math.min(layer.right, html.clientWidth) - 16,
      bottom: Math.min(layer.bottom, html.clientHeight) - 16,
    };
  }

  function shape(
    x: number,
    y: number,
    deg: number,
    dir: number,
    travel: number,
  ): Path {
    const big = wide();
    const a = (deg * Math.PI) / 180;
    return {
      x,
      y,
      dx: Math.cos(a) * dir,
      dy: Math.sin(a),
      travel,
      trail: big ? 72 : 48,
      half: big ? 16 : 12,
      thick: big ? 1.5 : 1,
    };
  }

  function randomPath(): Path | undefined {
    const big = wide();
    const p = shape(
      0,
      0,
      rand(15, 30),
      Math.random() < 0.5 ? -1 : 1,
      big ? rand(200, 280) : rand(120, 180),
    );
    // The corridor's box relative to the head's start; place it inside bounds.
    const nx = p.dy * p.half;
    const ny = Math.abs(p.dx) * p.half;
    const xs = [-p.dx * p.trail, p.dx * p.travel];
    const b = bounds();
    const x0 = b.left - (Math.min(...xs) - nx);
    const x1 = b.right - (Math.max(...xs) + nx);
    const y0 = b.top - (-p.dy * p.trail - ny);
    const y1 = b.bottom - (p.dy * p.travel + ny);
    if (x1 < x0 || y1 < y0) return undefined;
    return { ...p, x: rand(x0, x1), y: rand(y0, y1) };
  }

  /** The demo's fixed path (§13.3): 20°, toward the inline end, from inside the
      spacer (demo) or from the caption below it (demo-blocked). */
  function demoPath(): Path | undefined {
    const open = mode === "demo";
    const target = document.querySelector(
      `[data-sf-demo="${open ? "open" : "text"}"]`,
    );
    if (!target) return undefined;
    const big = wide();
    const r = target.getBoundingClientRect();
    const y = open ? (big ? 64 : 56) : 8;
    return shape(r.left + (big ? 104 : 76), r.top + y, 20, 1, big ? 240 : 160);
  }

  /** Samples at most 8px apart on five lines across the corridor; per sample:
      edge, then null, then open sky. The first failure names the reason. */
  function check(p: Path): Skip | undefined {
    const b = bounds();
    const length = p.trail + p.travel;
    const steps = Math.ceil(length / 8);
    for (let k = -2; k <= 2; k++) {
      const off = (k * p.half) / 2;
      for (let i = 0; i <= steps; i++) {
        const t = -p.trail + (i * length) / steps;
        const x = p.x + p.dx * t - p.dy * off;
        const y = p.y + p.dy * t + p.dx * off;
        if (x < b.left || x > b.right || y < b.top || y > b.bottom) {
          return "edge";
        }
        const hit = document.elementFromPoint(x, y);
        if (!hit) return "null";
        if (!hit.matches(OPEN_SKY)) return "text";
      }
    }
    return undefined;
  }

  /**
   * One launch attempt: up to three random paths, or the demo path checked three
   * times (the worst case). Each path is checked in its own task, so no task
   * does more than one corridor of hit tests; each task is one sf-attempt
   * measure. A random path launches as soon as it is open; the demo launches
   * in the task of its third check, and only if none of the three refused
   * (`refused` is carried from task to task).
   */
  function attempt(step = 0, refused = false): void {
    started = true;
    performance.mark("sf-attempt-start");
    let more = false;
    if (
      state === "animating" &&
      !flight &&
      performance.now() - lastScroll >= SCROLL_LOCK_MS &&
      !document.querySelector("dialog[open]")
    ) {
      const path = demo ? demoPath() : randomPath();
      const skip = path ? check(path) : "edge";
      if (skip) attr("data-sf-last-skip", skip);
      // Random paths are independent; the demo's three checks are one decision.
      refused = demo && (refused || skip !== undefined);
      more = step < 2 && (demo || skip !== undefined);
      if (!skip && !refused && !more) launch(path!);
    }
    performance.measure("sf-attempt", "sf-attempt-start");
    if (more) timer = window.setTimeout(attempt, 0, step + 1, refused);
    else schedule(demo ? DEMO_EVERY_MS : rand(10e3, 16e3));
  }

  /* ── The streak ── */

  function launch(p: Path): void {
    const el = document.createElement("span");
    el.setAttribute("data-sf-streak", "");
    el.style.width = `${p.trail}px`;
    el.style.height = `${p.thick}px`;
    slot.append(el);
    const deg = (Math.atan2(p.dy, p.dx) * 180) / Math.PI;
    // transform-origin is the head (the element's end), so the head sits on the path.
    const at = (t: number) =>
      `translate(${p.x + p.dx * t - p.trail}px,${p.y + p.dy * t - p.thick / 2}px) rotate(${deg}deg)`;
    const anim = el.animate(
      [
        { transform: at(0), opacity: 0 },
        { opacity: 1, offset: 0.15 },
        { opacity: 1, offset: 0.55 },
        { transform: at(p.travel), opacity: 0 },
      ],
      { duration: DURATION.fallingStar * 1000, easing: EASE_CSS.linear },
    );
    const observers: Observer[] = [];
    const main = document.getElementById("main");
    if (main) {
      // Only a real change of main's size cancels: the initial notification
      // reports the size recorded here.
      const { width, height } = main.getBoundingClientRect();
      const resize = new ResizeObserver((entries) => {
        for (const entry of entries) {
          const box = entry.borderBoxSize[0];
          if (
            box &&
            (Math.abs(box.inlineSize - width) > 0.5 ||
              Math.abs(box.blockSize - height) > 0.5)
          ) {
            cancel();
          }
        }
      });
      resize.observe(main, { box: "border-box" });
      const mutation = new MutationObserver(cancel);
      mutation.observe(main, {
        childList: true,
        subtree: true,
        characterData: true,
        attributeFilter: ["class", "style", "hidden", "open"],
      });
      observers.push(resize, mutation);
    }
    const current: Flight = { el, anim, observers };
    flight = current;
    count++;
    attr("data-sf-streaks", String(count));
    anim.finished.then(
      () => flight === current && drop(),
      () => {},
    );
  }

  function drop(): Flight | undefined {
    const f = flight;
    flight = undefined;
    f?.observers.forEach((o) => o.disconnect());
    f?.el.remove();
    return f;
  }

  /** At once, no fade: hidden in the same task, then removed. */
  function cancel(): void {
    const f = flight;
    if (!f) return;
    f.anim.cancel();
    f.el.style.opacity = "0";
    drop();
  }

  /* ── Triggers (§6.2) ── */

  function onInput(event: Event): void {
    lastInput = performance.now();
    if (SCROLLS.includes(event.type)) lastScroll = lastInput;
    cancel();
    if (state === "paused") update();
  }

  /** Plain bands in view below the header band; rootMargin takes px only. */
  function observe(): void {
    io?.disconnect();
    const seen = new Set<Element>();
    io = new IntersectionObserver(
      (entries) => {
        for (const entry of entries) {
          if (entry.isIntersecting) seen.add(entry.target);
          else seen.delete(entry.target);
        }
        visible = seen;
        update();
      },
      { rootMargin: `-${band}px 0px 0px 0px` },
    );
    const bands = document.querySelectorAll('[data-band="plain"]');
    bands.forEach((el) => io?.observe(el));
    if (bands.length === 0) {
      visible = seen;
      update();
    }
  }

  function measure(): void {
    const next = sky
      ? Math.ceil(
          sky.getBoundingClientRect().top - slot.getBoundingClientRect().top,
        )
      : 0;
    if (next === band) return;
    band = next;
    observe();
  }

  const onResize = () => cancel();
  const onPageShow = (event: PageTransitionEvent) => {
    if (event.persisted) update();
  };
  const skyObserver = new ResizeObserver(measure);
  const motionObserver = new MutationObserver(update);

  for (const type of INPUTS) {
    addEventListener(type, onInput, { passive: true });
  }
  addEventListener("resize", onResize);
  addEventListener("pageshow", onPageShow);
  document.addEventListener("visibilitychange", update);
  // A dialog or popover opening (toggle doesn't bubble; capture sees it).
  document.addEventListener("toggle", onResize, true);
  prefs.forEach((q) => q.addEventListener("change", update));
  bandQueries.forEach((q) => q.addEventListener("change", measure));
  motionObserver.observe(html, { attributeFilter: ["data-motion"] });
  if (sky) skyObserver.observe(sky);
  measure();

  return {
    onRouteChange() {
      cancel();
      count = 0;
      started = false;
      attr("data-sf-streaks", "0");
      slot.removeAttribute("data-sf-last-skip");
      clearTimeout(timer);
      if (state === "animating") schedule(demo ? 0 : rand(6e3, 12e3));
      observe();
    },
    destroy() {
      cancel();
      clearTimeout(timer);
      clearTimeout(idleTimer);
      io?.disconnect();
      skyObserver.disconnect();
      motionObserver.disconnect();
      for (const type of INPUTS) removeEventListener(type, onInput);
      removeEventListener("resize", onResize);
      removeEventListener("pageshow", onPageShow);
      document.removeEventListener("visibilitychange", update);
      document.removeEventListener("toggle", onResize, true);
      prefs.forEach((q) => q.removeEventListener("change", update));
      bandQueries.forEach((q) => q.removeEventListener("change", measure));
    },
  };
}

export const SF = {
  live: "/dev/starfield",
  still: "/dev/starfield/still",
  noStreak: "/dev/starfield/no-streak",
  demo: "/dev/starfield/streak-demo",
  blocked: "/dev/starfield/streak-blocked",

/**
 * Waits until the motion module has set the state (load + idle, then the IO).
 * A readiness wait, not a budget: 20s leaves room for a loaded machine.
 */
export async function waitForState(
  page: Page,
  state: "animating" | "paused" | "static",
  timeout = 20_000,
): Promise<void> {
  await page.waitForFunction(
    (s) =>
      document
        .querySelector("[data-starfield]")
        ?.getAttribute("data-starfield-state") === s,
    state,
    { timeout },
  );
}

/**
 * Boxes of the shown marks inside the slot. An SVG element under a
 * display:none group still reports checkVisibility() true, so ancestors are
 * walked instead.
 */
export function markBoxes(
  page: Page,
  selector: string,
): Promise<{ left: number; top: number; right: number; bottom: number }[]> {
  return page.evaluate((sel) => {
    const shown = (el: Element | null): boolean => {
      for (let e = el; e; e = e.parentElement) {
        if (getComputedStyle(e).display === "none") return false;
      }
      return true;
    };
    return [...document.querySelectorAll(sel)].filter(shown).map((el) => {
      const r = el.getBoundingClientRect();
      return { left: r.left, top: r.top, right: r.right, bottom: r.bottom };
    });
  }, selector);
}

/** Number of shown elements matching the selector (ancestors walked). */
export async function countShown(
  page: Page,
  selector: string,
): Promise<number> {
  return (await markBoxes(page, selector)).length;
}

/** Running animations inside the slot (twinkles, and a streak if one flies). */
export function slotAnimations(page: Page, selector = "[data-sf-tw]") {
  return page.evaluate((sel) => {
    const slotEl = document.querySelector("[data-starfield]")!;
    return slotEl
      .getAnimations({ subtree: true })
      .filter((a) => (a.effect as KeyframeEffect).target?.matches(sel))
      .map((a) => a.playState);
  }, selector);
}

/** The Container content box of the first section, and the header band's bottom. */
export function frame(page: Page) {

    const container = document.querySelector("main [data-open-sky]")!;
    const cs = getComputedStyle(container);
    const r = container.getBoundingClientRect();
    const sky = document

        .bottom,

  });

/** CDP: every layer with its compositing reasons and whether its node is a twinkle span. */
export async function layerSnapshot(cdp: CDPSession, page: Page) {
  let layers: { layerId: string; backendNodeId?: number }[] = [];
  const onChange = (event: { layers?: typeof layers }) => {
    if (event.layers) layers = event.layers;
  };
  cdp.on("LayerTree.layerTreeDidChange", onChange);
  await cdp.send("LayerTree.enable");
  // Two frames, so the tree reflects the current state.
  await page.evaluate(
    () =>
      new Promise((r) => requestAnimationFrame(() => requestAnimationFrame(r))),
  );
  await page.waitForTimeout(300);
  cdp.off("LayerTree.layerTreeDidChange", onChange);
  await cdp.send("DOM.getDocument", { depth: 0 });
  const out: { reasons: string[]; node: string }[] = [];
  for (const layer of layers) {
    let reasons: string[] = [];
    try {
      const r = await cdp.send("LayerTree.compositingReasons", {
        layerId: layer.layerId,
      });
      reasons = r.compositingReasonIds ?? [];
    } catch {

          backendNodeId: layer.backendNodeId,
        });

            if (this.closest("[data-starfield]")) return "slot";
            if (this.matches("main#main")) return "main";
            if (this.matches("body > header")) return "header";
            return this.tagName.toLowerCase();
          }`,
          returnByValue: true,
        });
        node = String(result.value);
      } catch {
        node = "";
      }
    }
    out.push({ reasons, node });
  }
  await cdp.send("LayerTree.disable");
  return out;

test("12. demo: launches, survives to its end, and scrolling hides it at once", async ({
  page,
}) => {
  await openDemo(page, SF.demo);
  // (a) Within 4s of animating.
  await expect(slot(page)).toHaveAttribute("data-sf-streaks", /^[1-9]/, {
    timeout: 4000,
  });
  // (b) and (c), with no input at all. Nothing here depends on wall-clock
  // bounds, which a loaded machine breaks (M1.20b). The mid-flight sample is the
  // first frame at or after 600ms, and it must fall before the fade-out starts:
  // getComputedTiming().progress at most the end of the opacity-1 plateau, read
  // from the keyframe offsets. A frame that lands late is no failure of the
  // streak, so the sample is retaken on the next streak (the demo relaunches
  // every 3s), at most 3 streaks. Every streak watched must survive to its end
  // and be removed. "Increments again at the next 3s attempt" is counted in
  // sf-attempt measures (one per check, read by count, not by timestamp): the
  // first attempt to run after the streak's end launches in its third check.
  const result = await page.evaluate(async () => {
    const slotEl = document.querySelector("[data-starfield]")!;
    const frame = () => new Promise((r) => requestAnimationFrame(r));
    const measures = () => performance.getEntriesByName("sf-attempt").length;
    // At the next change of data-sf-streaks: the measures so far (null after `ms`).
    const nextLaunch = (ms: number) =>
      new Promise<number | null>((resolve) => {
        const timer = setTimeout(() => {
          observer.disconnect();
          resolve(null);
        }, ms);
        const observer = new MutationObserver(() => {
          clearTimeout(timer);
          observer.disconnect();
          resolve(measures());
        });
        observer.observe(slotEl, { attributeFilter: ["data-sf-streaks"] });
      });
    const runs: {
      props: string[];
      plateauEnd: number;
      time: number;
      progress: number;
      opacity: number;
      connected: boolean;
      removed: boolean;
    }[] = [];
    let previous: Element | null = null;
    let measuresAtEnd = 0;
    for (let round = 1; round <= 3; round++) {
      // A streak in flight that has not reached 600ms yet, new each round.
      let el: HTMLElement | undefined;
      let anim: Animation | undefined;
      const deadline = performance.now() + 10_000;
      while (!el || !anim) {
        const found = slotEl.querySelector<HTMLElement>(
          ":scope > [data-sf-streak]",
        );
        const a = found?.getAnimations()[0];
        if (found && a && found !== previous && Number(a.currentTime) < 600) {
          el = found;
          anim = a;
        } else if (performance.now() > deadline) {
          throw new Error(`no fresh streak within 10s (round ${round})`);
        } else await frame();
      }
      previous = el;
      const effect = anim.effect as KeyframeEffect;
      const keyframes = effect.getKeyframes();
      const props = [
        ...new Set(
          keyframes
            .flatMap((k) => Object.keys(k))
            .filter(
              (k) =>
                !["offset", "computedOffset", "easing", "composite"].includes(
                  k,
                ),
            ),
        ),
      ].sort();
      // The fade-out starts at the last keyframe at full opacity.
      const plateauEnd = Math.max(
        ...keyframes
          .filter((k) => Number(k.opacity) === 1)
          .map((k) => k.computedOffset),
      );
      const finished = anim.finished; // rejects (AbortError) if cancelled
      while (anim.playState === "running" && Number(anim.currentTime) < 600)
        await frame();
      const sample = {
        time: Number(anim.currentTime),
        progress: Number(effect.getComputedTiming().progress),
        opacity: Number(getComputedStyle(el).opacity),
        connected: el.isConnected,
      };
      await finished;
      measuresAtEnd = measures();
      runs.push({ props, plateauEnd, ...sample, removed: !el.isConnected });
      if (sample.progress <= plateauEnd) break;
    }
    const measuresAtLaunch = await nextLaunch(10_000);
    const checks =
      measuresAtLaunch === null ? null : measuresAtLaunch - measuresAtEnd;
    return { runs, checks };
  });
  test.info().annotations.push({
    type: "demo streak samples",
    description: JSON.stringify(result),
  });
  for (const run of result.runs) {
    expect(run.props).toEqual(["opacity", "transform"]);
    expect(run.connected).toBe(true);
    expect(run.removed).toBe(true);
  }
  const mid = result.runs.at(-1)!;
  expect(mid.time).toBeGreaterThanOrEqual(600);
  expect(mid.progress).toBeLessThanOrEqual(mid.plateauEnd);
  expect(mid.opacity).toBeGreaterThan(0.5);
  // The next attempt launched: three checks after the end, the last one launching.
  expect(result.checks).toBe(3);
  // (d) A 1px scroll in flight: no visible streak in the next frame. The streak
  // is found and the scroll made in one task, so it cannot end in between.
  const after = await page.evaluate(async () => {
    const slotEl = document.querySelector("[data-starfield]")!;
    const frame = () => new Promise((r) => requestAnimationFrame(r));
    const deadline = performance.now() + 10_000;
    for (;;) {
      const el = slotEl.querySelector<HTMLElement>(":scope > [data-sf-streak]");
      const anim = el?.getAnimations()[0];
      if (el && anim?.playState === "running") {
        anim.finished.catch(() => {});
        window.scrollBy(0, 1);
        await frame();
        return {
          playState: anim.playState,
          hidden: !el.isConnected || getComputedStyle(el).opacity === "0",
        };
      }
      if (performance.now() > deadline) return null;
      await frame();
    }
  });
  expect(after).toEqual({ playState: "idle", hidden: true });
});

    (window as unknown as { __sfProbe: typeof probe }).__sfProbe = probe;
    new MutationObserver((records) => {
      for (const rec of records) {
        if (probe.launched) return;

          // A launch before the refusal would mean the cover was missed.
          if (!probe.removed) probe.earlyLaunches += 1;

            probe.launched = true;
            probe.measuresAtLaunch = measures();
            probe.streaks = Number(slotEl.getAttribute("data-sf-streaks"));
          }
        } else if (slotEl.getAttribute("data-sf-last-skip") === "text") {
          probe.texts += 1;
          if (!probe.removed) {
            cover.remove();
            probe.removed = true;
            probe.measuresAtRefusal = measures();
          }
        }
      }
    }).observe(slotEl, {
      attributeFilter: ["data-sf-last-skip", "data-sf-streaks"],
    });
    document.body.append(cover);
    return {
      streaks: Number(slotEl.getAttribute("data-sf-streaks")),
      skip: slotEl.getAttribute("data-sf-last-skip"),
    };
  });
  expect(before.skip).toBeNull();
  // The next attempt (every 3s) hits the cover on its first check; the attempt
  // after it, with the cover gone, launches again. A readiness wait.
  await page.waitForFunction(
    () =>
      (window as unknown as { __sfProbe: { launched: boolean } }).__sfProbe
        .launched,
    undefined,
    { timeout: 15_000 },
  );
  const probe = await page.evaluate(() => {
    const p = (
      window as unknown as {
        __sfProbe: {
          texts: number;
          earlyLaunches: number;
          streaks: number;
          measuresAtRefusal: number;
          measuresAtLaunch: number;
        };
      }
    ).__sfProbe;
    // sf-attempt measures (one per check) after the refused check, up to the launch.
    return { ...p, checks: p.measuresAtLaunch - p.measuresAtRefusal };
  });
  test.info().annotations.push({
    type: "refused then clear",
    description: JSON.stringify(probe),
  });
  expect(probe.earlyLaunches).toBe(0);
  expect(probe.texts).toBe(1); // only check 1 was refused
  // Checks 2-3 of the refused attempt (no launch), then the next attempt's
  // three checks, which launch: the refusal stopped that attempt.
  expect(probe.checks).toBe(5);
  expect(probe.streaks).toBe(before.streaks + 1);

/**
 * The bundled module around `at` in a Turbopack chunk: from its entry
 * (`<id>,e=>{` or `<id>,(e,t,r)=>{`) to the matching brace, strings skipped.
 */
function moduleAround(source: string, at: number): string {
  let start = -1;
  for (const m of source.matchAll(/[[,]\d+,\(?\w+(?:,\w+)*\)?=>\{/g)) {
    if (m.index >= at) break;
    start = m.index + 1;
  }
  if (start < 0) throw new Error("no module entry before the marker");
  let depth = 0;
  let quote = "";
  for (let i = source.indexOf("{", start); i < source.length; i++) {
    const c = source[i];
    if (quote) {
      if (c === "\\") i++;
      else if (c === quote) quote = "";
    } else if (c === '"' || c === "'" || c === "`") quote = c;
    else if (c === "{") depth++;
    else if (c === "}" && --depth === 0) return source.slice(start, i + 1);
  }
  throw new Error("unbalanced module");
}

test(
  "15. per attempt: sf-attempt within budget, never a long task",
  { tag: "@perf" },
  async ({ page }) => {
    await page.addInitScript(() => {
      const tasks: Span[] = [];
      (window as unknown as { __longTasks: Span[] }).__longTasks = tasks;
      new PerformanceObserver((list) => {

            a.startTime < t.startTime + t.duration,

        attempts: attempts.map((a) => a.duration).sort((a, b) => a - b),
        longTasks: overlapping.length,

    if (test.info().config.workers === 1) expect(median).toBeLessThanOrEqual(4);
